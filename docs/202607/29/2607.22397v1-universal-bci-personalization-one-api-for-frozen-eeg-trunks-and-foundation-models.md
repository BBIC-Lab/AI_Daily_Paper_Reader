## 摘要
冻结的脑电图编码器大量涌现；每模型微调的默认设置无法扩展。我们提出Nimbus个性化器：一种将编码约定到贝叶斯头部再到脑状态（可选仿射中间层）的方案，其可部署在异构冻结主干上，无需为每种架构构建新的个性化堆栈。论点（系统层面）：贡献在于主干无关的API——而不是将嵌入上的LDA作为机器学习创新——以便原始设备制造商一次集成即可更换主干。证据：相同的接口在五个经典主干（EEGNet、Shallow、Deep、Conformer、ATCNet）与四个运动想象数据集（18个单元格）上运行，并在同一个个性化器下运行基础编码器（REVE）。在存在嵌入容量的情况下，该头部是一个廉价的默认中点，与热启动微调或参数高效微调相比，其适应墙钟时间少几个数量级，同时恢复了大部分微调精度增益；仅在干净时校准在12/18个单元格中成立。头部增益是支持证据，表明该API在存在容量的情况下是有用的。被试级别的置信区间识别出最清晰的数据集，并在其他地方跨零。所有结果都是探索性的（被试级别的自助法，无验证性检验）；何时升级适应的决策逻辑在我们的控制层伴随工作中论述。

## Abstract
Frozen EEG encoders proliferate; per-model fine-tune defaults do not scale. We present Nimbus Personalizer: one contract encode to Bayesian head to BrainState (optional affine mid-tier) that sits on heterogeneous frozen trunks without a new personalization stack per architecture. Thesis (systems): the contribution is the trunk-agnostic API - not LDA-on-embeddings as an ML novelty - so OEMs integrate once and swap trunks. Evidence: the same surface runs on five classical trunks EEGNet, Shallow, Deep, Conformer, ATCNet x four MI datasets (18 cells) and on a foundation encoder (REVE) under the same Personalizer. Where embedding capacity exists, the head is a cheap default mid-point versus warm-start fine-tune or PEFT, costing orders of magnitude less adaptation wall time while recovering much of the fine-tune accuracy gain; calibration-only-when-clean holds in 12/18 cells. Head gains are supporting evidence that the API is useful where capacity exists. Subject-level confidence intervals identify the clearest dataset and span zero elsewhere. All results are exploratory (subject-level bootstrap, no confirmatory tests); the decision logic for when to escalate adaptation is addressed in our companion work on the control layer.

## 论文详细总结（自动生成）

### 1. 论文的核心问题与整体含义

- **核心问题**：随着冻结脑电图编码器（deep MI encoders）大量出现，每部署一个新模型就需要重新构建个性化适配栈（per-model fine-tune defaults），这无法满足工业化扩展需求。研究者希望提出一种与主干架构无关的个性化接口，使得异构的冻结模型能通过同一套合约（contract）完成被试间和会话间的漂移适应。
- **整体含义**：从系统架构角度贡献一个 **“主干无关的个性化API”**（Nimbus Personalizer），让OEM一次集成、随意更换冻结编码器。该API并不是提出全新分类算法，而是把经典的**贝叶斯头+脑状态输出**作为一种廉价的默认适配方案，仅在必要时允许升级到参数高效微调（PEFT）或全微调。

### 2. 方法论

- **核心思想**：将任意冻结编码器封装为一个统一的 `encode → Bayesian head → BrainState` 合约。冻结编码器仅提供从试验到嵌入矩阵 $Z\in\mathbb{R}^{n\times d}$ 的映射，个性化器在该嵌入上构建分类头并进行在线更新，完全不改变主干权重（除全微调逃生路径外）。
- **关键技术细节**：
  - **API 合约**：`wrap(model.encode)` 得到编码器，`Personalizer(encoder, head="lda", classes=...)` 包装，`adapter.fit(X_cal, y_cal)` 在少量校准数据上拟合头部，`adapter.predict(X_stream)` 输出含预测意图、置信度、不确定性和备选类别的结构化 `BrainState` 对象。
  - **个性化阶梯**（同一API内）：
    - **L0**：仅校准头部，不使用任何流转标注（adaptation-fit成本计为0）。
    - **L1**：在L0基础上，利用有标注适配试次在线更新贝叶斯头（默认LDA）。
    - **L2**：在L1之前先对嵌入 $Z$ 施加有监督仿射映射，再输入同一个头部。
    - **L3**（逃生路径）：全微调冻结编码器本身。
  - **头部家族**：默认LDA，可选QDA和Softmax。实验表明头部优选受数据集和压力类型影响，因此API保持头部模块化，LDA为安全默认。
  - **效用指标**：统一效用 $U = \text{accuracy} - \lambda_w\cdot t_\text{adapt} - \mu_n\cdot (n_\text{adapt}/N_\max)$，其中 $\lambda_w=0.02$（每秒适应墙钟时间等价于2个百分点精度），$\mu_n=0.05$（80试次标注块等价于5个百分点精度），用于公平比较不同成本的适配方案。

### 3. 实验设计

- **数据集与场景**：使用MOABB上的四个公开运动想象数据集：
  - BNCI2014-004（9名被试，2类）
  - Zhou2016（4名被试，3类）
  - Kumar2024（18名被试，2类）
  - Shin2017-A（29名被试，2类，适应试次限20）
  数据划分：校准=首session，适配=中间session，评估=末session。标注适配预算一般为40试次（Shin为20）。
- **基准与对比方法**：
  - 主干模型：5个经典卷积/注意力主干（EEGNet、ShallowConvNet、DeepConvNet、EEG Conformer、ATCNet）+ 1个基础模型（REVE）。
  - 对比臂：
    - 工厂主干自身的softmax分类器（`trunk softmax`，作为控制基线）
    - L0：仅校准个性化头（`cal-only`）
    - L1：流个性化头（`stream head`）
    - L2：仿射+头部
    - 线性探针（在冻结嵌入上训练，非阶梯级别）
    - 全微调（L3）
    - 对EEGNet和REVE进一步加入LoRA、仅微调末层等中间适配方案。
- **合成压力**：为了可控地模拟分布漂移，在适配和评估阶段的原始多通道EEG上施加合成通道混合（synthetic channel-mix stress），强度等级 $\{0,0.25,0.5,0.75\}$，而校准数据保持干净。另外也用幅度缩放、通道丢弃、SNR噪声等进行了头部家族的跨压力复制验证。

### 4. 资源与算力

- 文中提到部分实验使用 **CUDA** 和 **Modal L40S** GPU，报告了各方案的适应墙钟时间（约 ms 至 秒级别），例如L1/L2适配时间远小于1秒，全微调为0.05–0.8秒，REVE相关全微调更大。但未明确记录具体GPU型号、数量或训练时长。模型训练总时长未给出。

### 5. 实验数量与充分性

- **主要地图**：5个经典主干 × 4个数据集 = 20个单元格（但Kumar只评估3个主干，实际18个经典单元格），在此基础上比较不同阶梯级别、头部类型以及成本对比。
- **额外实验**：
  - 头部家族研究：在全部主干×数据集上对比LDA/QDA/Softmax的效用，并跨4种合成压力进行60个单元格的复制。
  - 成本对比：逐主干的Personalizer vs 全微调 vs 线性探针；EEGNet和REVE的加宽基线（LoRA等）。
  - 转移性分析：统计cal-only-when-clean和strict-ordinal规则在18个单元格中的成立频率。
- **充分性与公平性**：实验覆盖较多模型与数据集，统计采用被试级自助法（bootstrap）和95%置信区间，但作者明确声明所有结果为**探索性**，未进行验证性检验，且某些条件（如严格序数升级）仅在少数单元格中成立，统计置信区间宽。总体实验设计对不同方法公平，但合成压力局限于通道混合等几类，物理电极位移等真实情况未覆盖。

### 6. 主要结论与发现

- **API通用性**：同一套Personalizer接口无需修改即可在5个经典主干和REVE上运行，基本实现了主干无关的个性化路径。
- **成本与精度权衡**：
  - 在嵌入容量充足时，廉价贝叶斯头（L1/L2）能以**约2–40分之一的墙钟时间**恢复全微调（L3）带来的大部分精度提升，很多情况下甚至超过或持平全微调精度。
  - 在多数数据集和压力条件下，仅校准（L0）在干净数据上已经足够好（12/18单元格），流头部（L1）在中等和严重压力下帮助明显。
- **头部的局限性**：QDA在某些数据集（如BNCI）和通道混合压力下优于LDA，但这种优势并不通用（跨压力复制中LDA更稳定），因此LDA保留为安全默认，QDA作为可选项。
- **阶梯转移性**：校准-仅当干净（cal-only-when-clean）是较可靠的默认策略（12/18），而要求“严重压力→L2”的严格序数升级只在5/18单元格成立，属于数据集依赖的倾向。

### 7. 优点

- **系统设计亮点**：提供真正可跨模型部署的统一合约，与具体的编码器架构解耦，便于工业集成。
- **成本意识**：将墙钟时间和标注预算显式纳入效用评估，强调廉价头部是合理的默认选择，微调仅作有偿升级。
- **结构化输出**：不输出裸标签，而是附带置信度、不确定性和备选假设，直接支持下游决策引擎。
- **多维验证**：在多个主干、多个数据集、多种合成压力下进行了系统对比，并给出了被试层次置信区间，对结果的可靠性进行了谨慎评估。

### 8. 不足与局限

- **统计严谨性不足**：受限于数据集规模（BNCI n=9，Zhou n=4等），只能进行探索性分析，多数L1-L0、QDA-LDA增益的置信区间跨零，无法做出严格的统计推断。
- **压力覆盖有限**：主实验仅采用合成通道混合，物理电极位移、信噪比下降等真实场景未测试；跨压力复制虽增加了幅度缩放、通道丢弃和噪声，但仍属人工扰动。
- **阶梯规则不可靠**：严格序数升级模式不具有普适性，无法作为通用的调度逻辑。
- **基础模型精度**：基础编码器REVE的绝对精度仍低于任务专用训练的主干，论文仅主张API可以统一地廉价接入，并未达到性能领先。
- **控制层缺位**：何时升级适应的决策逻辑（资源分配的“控制层”）未在本工作中给出，留作伴随论文内容。
