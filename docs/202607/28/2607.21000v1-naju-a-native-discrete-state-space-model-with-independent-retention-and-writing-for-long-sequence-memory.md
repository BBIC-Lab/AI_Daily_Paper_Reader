## 摘要
长序列记忆追踪对循环状态提出了两个对立要求：长期范围内近乎无损地保留已存储的绑定，以及主动覆盖过时的绑定。在我们的诊断套件中，最强的有效基线往往只能很好地解决其中一方面。像 Mamba 这类连续时间参数化的状态空间模型通过连续时间系统的零阶保持离散化获得其离散循环；我们认为这种迂回对记忆追踪并非必要，因而直接对离散转移进行参数化。Naju（原生自适应连接单元）将循环更新分解为显式离散极点（可学习的遗忘门 $f_n$）、独立的写入增益 $i_n$ 以及依赖于输入的写入/读取映射，示意表示为 $x_n = f_n\odot x_{n-1} + i_n\odot(B_n u_n)$。由于 sigmoid 极点满足 $0<f_n<1$，每个冻结的局部坐标在构造上就是 Schur 稳定的，在一致有界假设下，整个时变循环满足衰减记忆/BIBO 界限，且无需稳定性正则化器。我们形式化阐明了耦合设计的核心结构限制：任何非扩张的互补单门循环会通过 $|r|+w\le 1$ 将有效保留 $r$ 与写入增益 $w$ 绑定，因此近乎完全的保留会强制写入变弱；将 $f_n$ 与 $i_n$ 解耦即可消除这一约束。实验表明，Naju 是唯一在四倍训练长度下仍能在保留和覆盖两方面保持强大性能的评估模型。除了诊断套件，我们还在 WikiText-103 语言建模、Long Range Arena 以及多查询联想回忆任务上对 Naju 进行了评估。在这些场景中，Naju 始终将强大的长程记忆能力与有竞争力或更优的性能结合在一起，在主要对比中超越了 Mamba 基线，同时与 Transformer 保持竞争并保有线性时间、线性内存的扩展性。

## Abstract
Long-sequence memory tracking places two opposing demands on a recurrent state: near-lossless retention of stored bindings over long horizons, and active overwriting of stale ones. In our diagnostic suite, the strongest efficient baselines tend to solve only one side well. Continuous-time-parameterized state-space models (SSMs) such as Mamba obtain their discrete recurrence by zero-order-hold discretization of a continuous-time system; we argue that this detour is unnecessary for memory tracking and parameterize the discrete transition directly. Naju (Native Adaptive Junction Unit) factorizes the recurrent update, schematically $x_n = f_n\odot x_{n-1} + i_n\odot(B_n u_n)$, into an explicit discrete pole (a learned forget gate $f_n$), an independent write gain $i_n$, and input-dependent write/read maps. Since the sigmoid pole satisfies $0<f_n<1$, each frozen local coordinate is Schur-stable by construction, and the full time-varying recurrence satisfies a fading-memory/BIBO bound under uniform boundedness assumptions, with no stability regularizer. We formalize the key structural limitation of coupled designs: any non-expansive complementary single-gate recurrence ties the effective retention $r$ and write gain $w$ through $|r|+w\le 1$, so near-complete retention forces weak writing; decoupling $f_n$ from $i_n$ removes this constraint. Empirically, Naju is the only evaluated model that remains strong on both retention and overwriting at 4x the training length. Beyond the diagnostic suite, we evaluate Naju on WikiText-103 language modeling, Long Range Arena, and multi-query associative recall. Across these settings, Naju consistently combines strong long-range memory with competitive or superior performance, outperforming the Mamba baselines in the principal comparisons while remaining competitive with the Transformer and preserving linear-time, linear-memory scaling.

- **核心问题**：现有模型存在结构性耦合：
    - 连续时间参数化的 SSM（如 Mamba）通过零阶保持（ZOH）离散化得到循环转移，但步长 $\Delta_n$ 同时影响转移矩阵 $\bar{A}_n$（保留）和输入映射 $\bar{B}_n$（写入），导致两者相互制约。
    - 互补单门循环（如 $x_n = (1-g_n)\bar{A}_n x_{n-1} + g_n\bar{B}_n u_n$）通过同一变量控制保留和写入，满足 $|r|+w\le 1$ 的约束，使得“近乎完美保留”必然导致“写入极弱”，反之亦然。
- **研究目标**：提出一种**原生离散**（Native Discrete）状态空间模型 Naju，**将保留（遗忘门 $f_n$）和写入（输入门 $i_n$）彻底解耦**，从而打破上述结构性权衡，实现在单一固定大小的循环状态内同时高效保留和覆写。

### 论文提出的方法论
- **核心思想**：直接参数化离散循环，将遗忘门 $f_n = \sigma(\cdot)$ 作为**显式的离散极点**，并用独立的输入门 $i_n = \sigma(\cdot)$ 控制写入强度。
- **核心递归更新**（核心公式）：
    $$x_n = f_n \odot x_{n-1} + i_n \odot (B_n h_n)$$
    - $x_n$ 为对角选择性 SSM 状态。
    - $f_n, i_n \in (0,1)$ 分别是保留和写入增益，相互独立。
    - $B_n$ 和 $C_n$ 是输入依赖的选择性写入和读出向量。
    - $h_n$ 是经短因果卷积和 SiLU 激活后的内容驱动。
- **读出与输出**：
    - 状态读出：$y_n = \alpha x_n C_n + D \odot h_n$，其中 $\alpha = 1/\sqrt{d_{\text{state}}}$ 为维度校正增益，$D$ 为直接前馈增益。
    - 块输出：结合 SiLU 门控调制和残差连接，形成完整的 Naju 块。
- **关键分析**：
    - **记忆核视角**：展开递归后，记忆核 $K_{n,m} = \alpha R_{m\to n} i_m C_n^T B_m$ 将保留（通过累积遗忘门 $R_{m\to n} = \prod_{j=m+1}^n f_j$）、写入（$i_m$）和读写方向（$B_m, C_n$）的作用完全分离开。
    - **稳定性**：由于 $f_n = \sigma(a_n) \in (0,1)$，每个冻结的局部坐标构造上就是 Schur 稳定的。文中进一步证明了在门 logits、输入驱动和读出参数一致有界假设下，全时变系统满足**衰减记忆/BIBO（有界输入有界输出）界限**，且**无需额外稳定性正则化器**。
    - **与 LSTM 的关系**：保留了 LSTM 式独立遗忘门和输入门的抽象模式，但其记忆载体是对角 SSM 状态，而非 LSTM 的非线性细胞状态，且兼容结合性并行扫描（associative scan）。

    - WikiText-103 上的学习率搜索、宽度扩展和门秩消融实验。
- **客观公平性**：论文力求公平。
    - 诊断套件中为所有模型制定了**统一的训练协议**（优化器、调度器、Epoch 数、训练长度）。
    - 明确指出参数计数差异，并通过匹配状态尺寸（如 Mamba $N=64$ vs. Naju $N=64$）进行比较。
    - 外部基准如 WikiText-103 采用**匹配 Token 预算**的方式训练，而非匹配步数。
    - 对 Transformer 的弱项进行了深入诊断（增加训练 Epoch 等），排除了单纯优化不足的解释。

### 主要结论与发现
- **最佳权衡性能**：Naju 是唯一在诊断套件中，于 4 倍训练长度下同时在保留（T2: 99%）和覆写（T4: 89%）方面保持**高准确率**的模型，占领了性能权衡图的“右上角”区域。
- **性能优势可迁移**：在匹配 $1.2B$ Token 预算的 WikiText-103 语言建模上，Naju 获得最低测试困惑度，显著优于 Mamba 和 Mamba-2，并在 $d_{model}=256$ 时与 Transformer 接近。在 LRA 整体平均分和状态匹配的 MQAR 上同样超越 Mamba 基线。
- **机制实证**：消融实验证实了独立保留/写入门参数化的必要性（降低门秩会损害质量）、特定初始化策略（保留优先 $b_f=5$，保守写入 $b_i=-2$）和读出增益归一化对提高大状态尺寸下的训练鲁棒性至关重要。
- **理论与工程价值**：理论上解耦设计消除了结构耦合，构造性地保证了稳定性。工程上证明了原生离散 SSM 可以在维持线性复杂度的同时，达到与 Transformer 可比的建模性能。

### 优点
- **概念简洁优雅**：通过简单而深刻的“解耦”思想，直击长序列建模中保留与覆写的核心矛盾。
- **理论与实证结合紧密**：从单门结构耦合的分析性证明（$|r|+w\le 1$），到记忆核分解、稳定性定理，再到一系列针对性实验，论证链条非常完整。
- **实验设计精巧**：专门设计的诊断套件（T2 和 T4）能精准衡量模型的保留与覆写能力，揭示了现有模型的片面性，有力地支撑了文章的核心论点。
- **公平比较**：通过在统一协议、匹配预算、匹配状态尺寸、并进行多种子统计等方式，使得结论更具说服力。
- **自然稳定性**：利用 Sigmoid 门直接作为极点，巧妙地在没有额外正则化损失的情况下保证了循环的稳定性，简化了训练。

### 不足与局限
- **参数规模不匹配**：Naju 的解耦门和独立的 $B$、$C$ 映射带来了比 Mamba 更大的参数开销（尤其在模型宽度增大时）。这是其性能提升的部分原因，但论文对此有明确说明。
- **效率的工程优化不足**：尽管有编译优化，Naju 在未编译或小规模下的执行速度仍慢于高度优化的 Mamba 等基线，且显存占用更高。其效率对门秩消融不敏感，意味着瓶颈可能在扫描实现和周边操作上，有进一步优化空间。
- **宽度扩展性受限**：在 WikiText-103 的宽度扩展实验中，Naju 在 $d_{model}=1024$ 时被 Transformer 反超，提示当前参数化和优化方法在大宽度下可能存在扩展瓶颈。
- **合成任务到真实场景的间隙**：诊断套件高度受控，而真实世界（如语言建模、LRA）的覆写需求可能更复杂。Naju 的覆写是经由门控的“软”替换，可能与需要“硬”删除的应用仍有距离。
- **缺乏超长序列端到端验证**：主要实验涉及长度 $2048$-$4096$，缺乏在数万甚至更长序列上（如长文档问答）与生产级 Transformer 或混合架构的直接对比。
