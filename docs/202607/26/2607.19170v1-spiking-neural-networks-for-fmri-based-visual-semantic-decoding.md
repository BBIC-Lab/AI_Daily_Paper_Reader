## 摘要
基于功能性磁共振成像（fMRI）的视觉解码旨在从测量的脑活动中恢复视觉信息，通常通过将fMRI响应映射到潜在视觉特征以用于下游解码任务。现有大多数方法学习从fMRI响应到由人工神经网络（ANN）提取的视觉特征的映射，但尚不清楚ANN衍生特征是否为脑解码提供了合适的目标。在本研究中，我们探究了脉冲神经网络（SNN）衍生的视觉特征作为fMRI视觉解码的替代目标。我们比较了一个ANN基线与来自同一架构家族的四个SNN变体，它们具有不同的脉冲动态特性。为了隔离目标特征的影响，所有模型使用相同的L2正则化线性fMRI到特征的解码器，仅改变用作回归目标的特征向量。与ANN基线相比，SNN衍生特征与fMRI响应的对齐更强，并提升了视觉语义解码性能。例如，在GoD数据集上，SNN衍生特征将特征预测误差从0.7707降至0.0282，并将top-1语义解码准确率从0.1800提升至0.4400。消融实验结果进一步表明，脉冲神经动态特性和时间仿真步数都对观察到的优势有所贡献。这些发现支持SNN衍生特征作为有效的大脑可解码视觉表征，并凸显了目标特征设计作为基于fMRI的视觉解码的重要组成部分。

## Abstract
Functional magnetic resonance imaging (fMRI)-based visual decoding aims to recover visual information from measured brain activity, commonly by mapping fMRI responses into latent visual features for downstream decoding tasks. Most existing methods learn mappings from fMRI responses to visual features extracted by artificial neural networks (ANNs), yet it remains unclear whether ANN-derived features provide suitable targets for brain decoding. In this study, we investigate spiking neural network (SNN)-derived visual features as alternative targets for fMRI-based visual decoding. We compare an ANN baseline with four SNN variants from the same architectural family, which differ in their spiking dynamics. To isolate the effect of the target features, all models use the same L2-regularized linear fMRI-to-feature decoder, while only the feature vectors used as regression targets are varied. Compared with the ANN baseline, SNN-derived features exhibit stronger alignment with fMRI responses and improve visual semantic decoding performance. For instance, on the GoD dataset, SNN-derived features reduce feature-prediction error from 0.7707 to 0.0282 and improve top-1 semantic decoding accuracy from 0.1800 to 0.4400. Ablation results further indicate that both spiking neural dynamics and temporal simulation steps contribute to the observed advantage. These findings support SNN-derived features as effective brain-decodable visual representations and highlight target feature design as an important component of fMRI-based visual decoding.

## 2. 论文提出的方法论
- **核心思想**：采用完全相同的 fMRI 到特征解码器（线性岭回归），仅仅更换作为回归目标的可视特征，以隔离特征空间本身的影响。
- **特征提取器**：
  - **ANN 基线**：标准 ResNet‑18，取其分类头之前的倒数第二层激活向量 $z_{\text{ANN}}$。
  - **SNN 变体**：基于 SEW‑ResNet‑18 骨架，保持与 ResNet‑18 相同的残差块结构和层数，仅将激活单元替换为脉冲神经元。使用四种不同脉冲动力学：LIF（泄漏积分发放）、PSN（并行脉冲神经元）、MPSN（带记忆的并行脉冲神经元）、BuSNN（爆发式脉冲神经元）。每个 SNN 在 $T$ 个离散时间步上处理输入，得到时间相关特征 $\{f^t_{\text{SNN}}\}$，最终通过对时间步求平均获得固定长度的表征 $z_{\text{SNN}} = \frac{1}{T}\sum_{t=1}^T f^t_{\text{SNN}}$。
- **fMRI‑to‑feature 解码器**：针对每种特征空间 $m$，独立训练一个线性映射 $\hat{z}^{(m)} = x^\top W_m$，其中 $x$ 是预处理后的体素响应。通过 L2 正则化最小二乘求解最优权重：
  $$W_m^* = \arg\min_{W_m} \sum_{(x_i,I_i)} \|x_i^\top W_m - z_i^{(m)}\|_2^2 + \lambda \|W_m\|_F^2$$
  训练和解码流程保持一致，仅因目标特征维度 $d_m$ 不同而使矩阵形状不同。
- **下游评估**：解码后的特征 $\hat{z}$ 被送入对应视觉编码器的分类头用于语义分类；作为查询向量在相同特征空间进行图像检索；通过预测的语义标签驱动预训练文本到图像扩散模型进行语义引导的图像重建。

## 6. 论文的主要结论与发现
- **SNN 特征的可解码性更强**：在相同线性解码器下，SNN 衍生特征比 ANN 基线更易从 fMRI 数据预测。GoD 数据集上 MSE 从 0.7707 降至最低 0.0282，NSD 上从 0.7304 降至 0.0123。
- **语义解码性能提升**：SNN 特征的 Top‑1 语义一致性在 GoD 从 0.1800 提高至 0.4400（LIF），在 NSD 从 0.2342 提高至 0.4206（PSN）。
- **检索与重建改进**：多数 SNN 变体在图像检索和语义引导重建上优于 ANN 基线，PSN 表现尤其突出。
- **脉冲动态与时间步均起贡献**：不同脉冲神经元模型在误差降低和语义保持上各有侧重；时间步 $T=4$ 取得最佳折中，过短或过长均使性能下降。
- **体素水平对齐验证**：在 Mini‑Algonauts 2021 的多个视觉皮层区，SNN 表征的 PCC 分布显著高于 ANN 基线，说明其与血氧水平依赖信号的内禀对应更紧密。

## 7. 优点
- **严格的控制变量设计**：通过固定解码器架构与训练协议，纯粹考察目标特征的影响，排除解码器复杂度差异带来的混淆。
- **多层级、跨数据集评估**：从体素相关性、特征预测误差、分类一致性、检索到重建，且在不同数据集上重复验证，全面性强。
- **多种脉冲神经元模型对比**：覆盖 LIF、并行、记忆、爆发等多种动力学，证明优势并非某一种实现所特有，提升了结论的普适性。
- **明确的消融分析**：分别分析脉冲动态和时间步数的影响，帮助理解性能增益的来源。
- **视角创新**：将特征空间设计提升为解码建模的核心科学问题，为未来脑解码研究提供了新的思考框架。

## 8. 不足与局限
- **仅使用线性解码器**：虽然有意保持简单以凸显特征差异，但可能低估了特征的可解码潜力；更复杂、非线性的解码器是否会改变相对排序未验证。
- **模型范围局限**：对比仅基于 ResNet‑18 骨架，未涉及 Vision Transformer、多模态模型 (如 CLIP) 等当前主流 ANN 架构，SNN 特征的相对优势在这些模型上尚不明确。
- **重建仅为语义引导**：图像重建并非直接像素级解码，而是依赖语义标签驱动扩散模型，评估依赖特征相似度和综合分数，缺少人类感知评价，可能难以反映细粒度的视觉信息恢复。
- **统计检验不够全面**：体素级对齐使用了 Welch’s t‑检验，但下游任务（如 MSE、分类）未提供跨受试或重复测量的置信区间检验。
- **算力与实时性未讨论**：SNN 仿真时间步会引入额外计算开销，文中未分析训练或推理效率。预训练成本、时间步对解码速度的影响均未涉及。
- **个体差异处理**：实验仅限于特定数据集内的混合受试分析（GoD）或单一受试（NSD），跨受试编码与解码的泛化能力有待进一步检验。
