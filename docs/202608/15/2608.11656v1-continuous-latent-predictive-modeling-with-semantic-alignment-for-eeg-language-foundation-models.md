## 摘要
近年脑电基础模型的进展表明，大规模预训练有望实现跨受试者、记录环境和数据集的泛化神经解码。然而，主流预训练范式面临关键挑战：掩码自编码倾向于优先重建低级信号而非任务相关语义，而自回归建模导致连续神经动态与离散 token 空间之间的不匹配。为应对这些挑战，需要新的策略来有效对齐连续脑电表征与自然语言语义，并使其能够与大语言模型集成。因此，我们提出脑潜在预测模型（BLPM），一种脑电-语言基础模型，将异构脑电解码任务重新定义为连续语义嵌入预测问题。BLPM 引入了连续脑电潜在预测（CELP）编码器，通过潜在目标预测学习可迁移表征。在这些表征基础上，多查询语义分解（MQSD）模块提取任务相关信息，并根据语义关系在共享潜在空间中对齐连续脑电表征与文本语义。多个基准上的实验表明，跨多种任务具有一致的泛化性能，确立了连续潜在语义预测作为脑电-语言基础模型的有效范式。

## Abstract
Recent advances in EEG foundation models have demonstrated the potential of large-scale pretraining to enable generalizable neural decoding across subjects, recording environments, and datasets. However, dominant pretraining paradigms face key challenges: masked autoencoding tends to prioritize low-level signal reconstruction over task-relevant semantics, while autoregressive modeling creates a mismatch between continuous neural dynamics and discrete token spaces. To address these challenges, new strategies are needed to effectively align continuous EEG representations with natural-language semantics and enable their integration with large language models. Accordingly, we propose Brain Latent Predictive Model (BLPM), an EEG-language foundation model that reformulates heterogeneous EEG decoding tasks as a continuous semantic embedding prediction problem. BLPM introduces a Continuous EEG Latent Predictive (CELP) encoder that learns transferable representations through latent target prediction. Building on these representations, a Multi-Query Semantic Decomposition (MQSD) module extracts task-relevant information and aligns continuous EEG representations with textual semantics within a shared latent space according to their semantic relationships. Experiments across multiple benchmarks demonstrate consistent generalization performance across diverse tasks, establishing continuous latent semantic prediction as an effective paradigm for EEG-language foundation models.

## 2. 论文提出的方法论

BLPM 由三阶段组成：连续 EEG 潜在预测编码器（CELP）预训练、语言引导的多查询语义对齐（MQSD）、多任务指令微调与语义匹配。

### 2.1 Continuous EEG Latent Predictive Encoder（CELP）

- **输入构建**：将 EEG 数据 $X_{EEG} \in \mathbb{R}^{C \times T}$ 按通道切分为长度 $L$ 的非重叠片段，得到 token 序列 $X \in \mathbb{R}^{C \times P \times L}$，共 $N = C \times P$ 个 token。
- **双分支 patch embedding**：
  - 时间分支用 1D 卷积捕捉局部时间动态；
  - 频谱分支对片段做 FFT，并将幅度谱通过线性层投影到同一 $d$ 维空间；
  - 两者相加，再施加深度可分离卷积位置编码，得到 $\tilde{Z} \in \mathbb{R}^{N \times d}$。
- **联合潜在预测预训练**：采用类似 JEPA 的结构，包括在线编码器 $f_\theta$、目标编码器 $f_{\bar\theta}$ 和嵌入预测器 $g_\phi$。
  - **结构化多块掩码**：对通道–时间 token 序列施加可见掩码 $M_v$ 和多个预测掩码 $\{M_p\}$，包括时间跨度和通道块掩码，促使模型利用时间连续性与通道依赖。
  - **在线编码器**：只输入可见 token，得到 $H_v = f_\theta(\tilde{Z}_{M_v})$。
  - **目标编码器**：处理完整 token 序列，参数通过 EMA 更新：$\bar\theta^{(k)} \leftarrow m_k \bar\theta^{(k-1)} + (1-m_k)\theta^{(k)}$，提供稳定潜在预测目标。
  - **嵌入预测器**：根据可见上下文和可学习掩码 token，预测被掩码位置的潜在表示 $\hat{H}_{M_p} = g_\phi(H_v, m + p_{M_p})$。
  - **损失函数**：在潜在空间计算 Smooth L1 损失：
    $$
    \mathcal{L}_{CELP} = \frac{1}{|\mathcal{M}|} \sum_{M_p \in \mathcal{M}} \frac{1}{|M_p|} \sum_{i \in M_p} \rho(\hat{h}_i, \text{LN}(h_{t,i}))
    $$
    其中 $\rho$ 为 Smooth L1，$\text{LN}$ 为层归一化。
  - 预训练完成后，仅保留在线编码器作为 EEG 编码器骨干。

### 2.2 Language-Guided Multi-Query Semantic Decomposition（MQSD）

- **连续 EEG 表征**：冻结 CELP 编码器，输出扁平化 token 序列 $h \in \mathbb{R}^{N \times d}$，直接作为多查询交叉注意力的 key 和 value。
- **语言引导语义查询**：定义 $M$ 个固定语义查询（对应时间动态、频谱特征、空间关系、形态模式等），每个查询用 LLM 输入嵌入层 token 化并嵌入，得到 $Q_m \in \mathbb{R}^{L_{max} \times d_{LM}}$，并有注意力掩码屏蔽 padding。
- **多查询 EEG 分解**：
  - 每个查询独立对 EEG token 做交叉注意力：$R_m = \text{CrossAttn}(Q_m, h, h)$；
  - 对语言 token 维度做掩码平均池化：$\tilde{s}_m = \text{Pool}_{tok}(R_m)$；
  - 线性投影到 LLM 隐藏维度：$s_m = P_h(\tilde{s}_m) \in \mathbb{R}^{d_{LM}}$；
  - 收集所有查询得到 $S_q = [s_1; s_2; \dots; s_M] \in \mathbb{R}^{M \times d_{LM}}$。
- **语言初始化的语义嵌入预测器**：
  - 将 EEG token 投影到 LLM 空间：$u = P_u(h)$；
  - 拼接 $S_q$ 和 $u$，输入预测器 $G$（由预训练 LLM 解码器层构成，但使用双向注意力掩码而非因果掩码）；
  - 取前 $M$ 个语义查询对应的隐藏状态 $H_q = H_{1:M}$；
  - 对查询状态做平均池化：$h_{pred} = \frac{1}{M}\sum_{m=1}^M H_{q,m}$；
  - 通过预测头 $P_e$ 映射并 L2 归一化：$z_e = \text{norm}(P_e(h_{pred}))$。
- **自然语言语义目标**：类别标签 $y$ 表示为语义文本 $\ell_y$，用预训练文本嵌入模型编码并归一化：$z_y = \text{norm}(E_{text}(\ell_y))$。
- **语义对齐目标**：使用双向多正例 InfoNCE 对比损失，相似度 $A_{ij} = z_{e,i}^\top z_{y,j} / \tau$，最终损失为 $\mathcal{L}_{align} = \frac{1}{2}[L_{e \to t} + L_{t \to e}]$，同一语义文本的样本互为正例。

### 2.3 多任务指令微调与语义匹配推理

- **指令条件语义预测**：将任务指令 $s_k$ 用 LLM 输入嵌入得到 $T_k$，与 $S_q$、$u$ 拼接后输入非因果 LLM 预测器 $G$，得到 $H^{(k)} = G([T_k; S_q; u])$。
- **预测答案嵌入**：与对齐阶段类似，取语义查询位置的状态池化并通过答案预测头 $P_a$ 后归一化：
  $$
  \hat{z} = \text{norm}\left(P_a\left(\text{Pool}_{qry}\left(H^{(k)}_q\right)\right)\right)
  $$
- **指令微调目标**：同样使用双向多正例 InfoNCE 损失，将预测答案嵌入 $\hat{z}$ 与目标语义嵌入 $z_y$ 对齐。
- **推理**：对任务 $k$ 的候选答案文本编码得到 $\{z_c\}$，通过余弦相似度选择：
  $$
  \hat{y} = \arg\max_{c \in C_k} \hat{z}^\top z_c
  $$
  无需自回归生成，计算开销小。

  - COG-BCI：心理负荷分类（3 类）

  - PhysioNet-MI：运动想象分类（4 类）
  - FACED：情绪识别（9 类）
  - HMC：睡眠分期（5 类）

- **基线模型（7 个）**：
  - 任务特定：EEGNet、EEGConformer
  - 基础模型：BIOT、LaBraM、CBraMod、REVE、LUNA

### 3.2 预训练与实现细节

- **预处理**：TUEG 保留 5 分钟以上记录，丢弃首尾各 1 分钟，保留 10-20 标准导联，带通 0.3–75 Hz，陷波 60 Hz，重采样至 200 Hz，切分为 30 秒片段，剔除幅值超过 100 μV 的片段。
- **下游预处理**：对每个数据集使用 NeuralSet/NeuralBench 复现基线原始预处理，并采用模型特定预处理。
- **LLM 骨干**：Llama 3.2-1B-Instruct，并用 LoRA 进行参数高效适配（rank=8，alpha=16，dropout=0.05，目标模块 $q\_proj$、$v\_proj$）。

## 6. 论文的主要结论与发现

- **总体性能**：
  - BLPM 在 6/7 个数据集上取得了最佳 Balanced Accuracy，在 PhysioNet-MI 上排名第二（仅次于 REVE，差距仅 1.2%）。
  - 相对任务特定模型，BLPM 在 Mental Arithmetic、TUEV、PhysioNet-MI 上分别提高 14.0%、10.6%、9.9%。
  - 相对最强基础模型，BLPM 在 FACED 上提高 2.3%，Mental Arithmetic 提高 2.1%，TUEV 提高 1.9%，同时在 COG-BCI、TUAB、HMC 上也保持领先。
- **消融发现**：
  - 用输入空间重建替代潜在预测，性能下降最多 2.55 个百分点，说明潜在预测优于掩码重建。
  - 移除语义对齐阶段，性能显著下降，FACED 上最大降幅达 6.91 个百分点，证明跨模态对齐至关重要。
  - MQSD 优于全局池化和普通可学习查询，说明语言引导的多查询分解能提取互补语义。
  - 连续语义嵌入预测优于自回归 token 预测，在三个数据集上分别提升 1.91%、1.37%、1.14%。
- **可视化结论**：t-SNE 显示语义对齐后，同一数据集和同一类别的样本分布更紧凑、类间结构更清晰。

- **标签语义的简单性**：类别标签被转换为简短语义文本，但不同任务间文本模板可能影响对齐效果，论文未对文本模板设计进行消融。  
- **通道与采样率归一化**：虽然 TUEG 统一到 20 导联和 200 Hz，但不同下游数据集原始导联和采样率不同，论文未详细说明如何将 CELP 适配到不同 channel montage，这可能是实际部署中的隐患。  
- **模型可解释性有限**：虽然可视化了 t-SNE，但对 MQSD 每个语义查询具体学到了什么神经生理模式缺乏定量分析，难以确认“语义分解”是否具有神经科学可解释性。
