## 摘要
无监督时间序列域适应（DA）旨在解决在分布偏移下将分类器从有标签的源域迁移到无标签的目标域的问题，这些偏移可能由不同用户、传感器、设备、采集条件或时间动态引起。现有方法通常通过对抗训练、最优传输或基于矩的差异来对齐边缘特征分布，以缓解这种偏移。本文提出类条件路径分布对齐（CPDA），一种非对抗的、基于差异的框架，它对源域和目标域的类条件隐路径分布进行对齐，而不仅仅对齐全局特征边缘分布。CPDA引入了一种复合签名-谱核，联合捕获池化语义特征、时间路径结构、频域信息和低秩路径签名动态，同时利用源标签和目标软伪标签执行保持类别的对齐。我们进一步给出理论分析，表明CPDA定义了一个有效的核差异，现有基于矩匹配的方法可视为其受限特例，并得到一个类条件目标风险界。在13个不同的时间序列DA基准上，使用CNN、ResNet18和TCN骨干网络的大量实验表明，CPDA相对于30个差异、对抗和伪标签基线方法具有有效性。

## Abstract
Unsupervised time-series domain adaptation (DA) addresses the challenge of transferring a classifier from a labeled source domain to an unlabeled target domain under distribution shifts induced by different users, sensors, devices, acquisition conditions, or temporal dynamics. Existing methods typically mitigate this shift by aligning marginal feature distributions through adversarial training, optimal transport, or moment-based discrepancies. In this paper, we propose Class-Conditional Path Distribution Alignment (CPDA), a non-adversarial discrepancy-based framework that aligns source and target class-conditional latent path distributions rather than only global feature marginals. CPDA introduces a composite signature-spectral kernel that jointly captures pooled semantic features, temporal path structure, frequency-domain information, and low-rank path-signature dynamics, while using source labels and target soft pseudo-labels to perform class-preserving alignment. We further provide a theoretical analysis showing that CPDA defines a valid kernel discrepancy, admits existing moment-matching methods as restricted cases, and yields a class-conditional target-risk bound. Extensive experiments with CNN, ResNet18, and TCN backbones on 13 different time-series DA benchmarks demonstrate the effectiveness of CPDA against 30 discrepancy, adversarial, and pseudo-labeling baselines.

- **研究背景**：无监督时间序列域适应（Unsupervised Time-Series Domain Adaptation, UDA）的目标是把在带标签源域上训练的分类器迁移到无标签目标域，同时应对由用户、传感器、设备、采集条件或时间动态引起的分布偏移。
- **核心问题**：现有方法多通过对抗训练、最优传输或矩匹配来对齐 **边缘特征分布** $P_s(Z)\approx P_t(Z)$，忽略了类别结构与时间路径信息，可能导致跨类错误对齐，并丢失时间顺序、动态演化与频域结构。
- **本文意义**：提出 CPDA（Class-Conditional Path Distribution Alignment），对齐 **类条件隐路径分布** $P_s(Z_{1:T}|Y=c)\approx P_t(Z_{1:T}|Y=c)$，并给出理论风险界与大量实验验证，为时间序列域适应提供了一种非对抗、可解释的替代方案。

## 2. 论文提出的方法论

### 2.1 核心思想

- 不再只对齐全局特征边际，而是利用源域真实标签与目标域软伪标签，对每一类 $c$ 的隐时间路径分布进行加权 MMD 对齐。
- 通过复合签名–谱核（signature–spectral kernel）同时捕获：
  - **池化语义特征** $\psi_{pool}(x)=\frac1T\sum_{t=1}^T z_t$；
  - **时间路径特征** $\psi_{path}(x)=\mathrm{vec}(A_\theta(x)_1,\dots,A_\theta(x)_T)$，其中 $A_\theta(x)_t=[t/T,z_t,\Delta z_t]$；
  - **频域特征** $\psi_{spec}(x)=\mathrm{vec}\big(\log(1+|F_t[Z_\theta(x)]|^2)\big)$；
  - **低秩路径签名特征** $\psi_{sig}(x)=[S_1(x),\mathrm{vec}(S_2(x))]$，其中 $S_1(x)=\sum_{t=1}^{T-1}u_t$，$S_2(x)=\sum_{1\le i<j\le T-1}u_i\otimes u_j$，$u_t=P(\tilde Z_\theta(x)_{t+1}-\tilde Z_\theta(x)_t)$，$P$ 为固定随机投影矩阵。

### 2.2 复合核与类条件 MMD

- 对每个表示 $a\in\{\text{pool},\text{path},\text{spec},\text{sig}\}$ 构造多带宽高斯核 $k_a$，最终复合核为
  $$k_{CPDA}(x,x')=\alpha_{sig}k_{sig}+\alpha_{spec}k_{spec}+\alpha_{path}k_{path}+\alpha_{pool}k_{pool}.$$
- 类条件权重：
  $$w^s_{i,c}=\mathbb I[y_i^s=c],\quad w^t_{j,c}=q_{\theta,\phi}(c|x_j^t),$$
  归一化后得到 $\bar w^s_{i,c},\bar w^t_{j,c}$。
- 类条件经验均值嵌入：
  $$\hat\mu_{s,c}=\sum_i \bar w^s_{i,c}k_{CPDA}(x_i^s,\cdot),\quad \hat\mu_{t,c}=\sum_j \bar w^t_{j,c}k_{CPDA}(x_j^t,\cdot).$$
- CPDA 差异：
  $$\hat D^2_{CPDA}=\sum_{c=1}^K \hat\pi_t(c)\|\hat\mu_{s,c}-\hat\mu_{t,c}\|^2_{\mathcal H_{CPDA}},$$
  其中 $\hat\pi_t(c)=\frac1{n_t}\sum_j q_{\theta,\phi}(c|x_j^t)$ 为目标类先验估计。

### 2.3 训练目标

- 总损失：
  $$L_{CPDA}=L_{cls}+\lambda \hat D^2_{CPDA}+\eta L_{IM}+\gamma L_{VAT},$$
  其中 $L_{cls}$ 为源分类交叉熵，$L_{IM}$ 为目标信息最大化正则（鼓励置信预测并防止类坍缩），$L_{VAT}$ 为虚拟对抗训练，用于稳定伪标签对齐。

### 2.4 理论结果

- 证明 $k_{CPDA}$ 为正半定核。
- CPDA 是积分概率度量（IPM）。
- 类条件目标风险界：
  $$R_t(h)\le R_s^{\pi_t}(h)+B\sum_{c=1}^K\pi_t(c)MMD_{CPDA}(P_s^c,P_t^c).$$
- 伪标签误差对目标风险的影响被 $M\eta_q$ 控制。
- MMD、CORAL、DAN、HoMM 等可视为 CPDA 的受限特例。
