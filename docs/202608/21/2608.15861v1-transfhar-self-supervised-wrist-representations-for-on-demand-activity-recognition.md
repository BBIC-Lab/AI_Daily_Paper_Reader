## 摘要
细粒度腕部活动识别能够支持程序步骤引导和上下文感知辅助等应用，但为每个新任务、用户和活动粒度获取标注数据仍是一个瓶颈。我们提出了 TransfHAR，一种自监督腕部 IMU 框架，通过从全局未标注活动中学习可迁移的运动先验，实现按需的细粒度活动识别。我们表明，在粗略腕部 IMU 活动（如坐、行走、锻炼）上进行自监督预训练所学到的运动结构足够丰富，可迁移到预训练中未出现的细粒度操作类、手势类和程序类活动（如打响指、搅拌、挥手）。我们将 TransfHAR 实现为实时智能手表应用，允许用户定义并扩展自己的活动集，仅用少量演示即可实现个性化识别。在三个离线跨数据集评估中，TransfHAR 与使用完整标签集且具有相同或更多传感器通道的全监督基线相比，平均平衡准确率高出 6.2 个百分点，达到或超过其水平。在一项实验室研究中，10 名参与者各自执行七种新腕部活动，每类五个示例时 TransfHAR 跨参与者达到 86.7% 的平衡准确率；当每类仅用一段一分钟记录进行更新时达到 90.4%。这些结果表明，广泛的腕部自监督预训练为按需细粒度活动识别提供了有效基础。

## Abstract
Fine-grained wrist activity recognition can support applications such as procedural step guidance and context-aware assistance, yet acquiring labeled data for every new task, user, and activity granularity remains a bottleneck. We present TransfHAR, a self-supervised wrist IMU framework for on-demand, fine-grained activity recognition by learning transferable motion priors from global, unlabeled activities. We show that self-supervised pretraining on coarse wrist IMU activities (e.g., sitting, walking, exercise) learns motion structure rich enough to transfer to fine-grained manipulative, gestural, and procedural activities (e.g., snapping, stirring, waving) that are absent from pretraining. We implement TransfHAR as a real-time smartwatch application that lets users define and expand their own activity set for personalized recognition from only a few demonstrations. Across three offline cross-dataset evaluations, TransfHAR matches or exceeds fully supervised baselines that use complete label sets with equal or additional sensor channels, by 6.2 balanced-accuracy points on average. In an in-lab study with 10 participants each performing seven novel wrist activities, TransfHAR reaches 86.7% balanced accuracy across participants with five examples per class and 90.4% when updated from a single one-minute recording per class. These results indicate that broad self-supervised wrist pretraining provides an effective foundation for on-demand fine-grained activity recognition.

- **整体含义**：TransfHAR 提出一种“通用运动先验 + 轻量个性化适配”的范式，使用户能够在智能手表上按需定义、扩展自己的活动词汇，无需重新训练完整模型。

## 2. 论文提出的方法论

### 2.1 总体框架

- **两阶段框架**：
  - **Stage A**：在公共腕部 IMU 数据上自监督预训练 ViT-1D 编码器，仅使用粗粒度 L1/L2 活动，丢弃所有标签。
  - **Stage B**：冻结编码器，在其上训练轻量线性探针，用于用户定义的细粒度 L3/L4 活动分类。

### 2.2 数据对齐与运动复杂度分类

- **数据标准化**：将所有公共数据集转换为腕部单侧 50 Hz 连续流，统一为 forward-left-up（FLU）坐标轴，进行 24 Hz 四阶 Butterworth 低通滤波、逐通道 z-score 归一化。
- **运动复杂度四层分类**：
  - L1 准静态：重力主导、低频漂移（坐、站、躺）。
  - L2 运动性：准周期、有明显主频峰（走、跑、骑行）。
  - L3 操作类：非周期、幅度变化、无稳定主频（切菜、打字、搅拌）。
  - L4 程序类：短窗口内与 L3 相似，需时序上下文才能区分（烹饪步骤、拿铁制作步骤）。
- **数据分布不平衡**：公共数据中 L1/L2 占绝大多数（约 2541 小时），L3 较少（约 212 小时），L4 极稀缺（约 7 小时）。

### 2.3 编码器架构与自监督预训练

- **ViT-1D 编码器**：改编自 LSM-2，直接处理原始时序信号。
  - 对每个传感器通道独立使用共享 1D 卷积（kernel size/stride = 4），每个通道产生 32 个 patch token。
  - 使用可学习的 2D 位置编码，分别编码时间位置和通道身份。
  - Transformer 编码器：12 层、隐藏维度 384、6 个注意力头、前馈层 4 倍扩展、GELU 激活。
  - 训练时移除被掩码的 token，仅处理可见 token；推理时对所有 token 处理并做均值池化，得到 384 维窗口表征。
- **输入窗口**：2.56 秒（128 采样点，50 Hz），50% 重叠；支持 3-axis（仅加速度计）和 6-axis（加速度计+陀螺仪）两种输入，分别产生 96 和 192 个 token。
- **掩码自编码（MAE）目标**：
  - 每步掩盖 65% 的 patch token，编码器仅处理剩余可见 token。
  - 轻量解码器（4 层，隐藏 192，4 头）重建被掩码 patch。
  - 损失函数为仅在掩码位置计算的均方误差：$\mathcal{L} = \frac{1}{|\mathcal{M}|} \sum_{i \in \mathcal{M}} \| \hat{x}_i - x_i \|^2$，其中 $\mathcal{M}$ 为被掩码位置集合。
- **复合掩码策略**：每个样本随机选择三种模式之一：
  - 随机掩码：在所有 token 中随机掩码。
  - 时间掩码：跨所有通道掩盖选定的时间步。
  - 通道掩码：跨所有时间步掩盖选定的通道。
- **优化设置**：AdamW，学习率 $1.5 \times 10^{-4}$，$\beta=(0.9,0.95)$，权重衰减 $10^{-4}$，余弦学习率调度，1000 步 warm-up，FP16 混合精度，batch size 512，梯度裁剪 norm 1.0。

### 2.4 下游适配与部署

- **线性探针**：单层全连接，尺寸 $384 \times C + C$，其中 $C$ 为当前用户定义类别数。仅更新探针参数，编码器冻结。
- **探针训练**：AdamW，学习率 $5 \times 10^{-4}$，batch size 256，逆频率类别加权交叉熵损失，基于验证平衡准确率早停（patience 40）。
- **部署实现**：Apple Watch Series 10，Swift + Core Motion 采集 IMU，Core ML 运行编码器推理，本地完成特征缓存、探针训练和实时分类。
- **性能开销**：编码器推理 + 探针预测约 23.8 ms/窗口（刷新间隔 1.3 s）；7 类探针训练约 709–794 ms（K=1,5,10,20）；编码器 21.4 M 参数、8.83 GFLOPs/窗口、约 40.8 MB（FP16）。
