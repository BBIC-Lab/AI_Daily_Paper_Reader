## 摘要
机器学习流水线通常将关系数据扁平化为单表表示，丢弃了结构约束。广泛使用的基于 Shapley 值的特征归因方法随后依赖特征独立性，在底层数据中不可能出现的组合上评估模型，从而产生误导性解释。我们提出 RelShap，一个将关系约束和数据来源纳入 Shapley 值计算的框架，将背景数据和联盟评估限制在关系有效的配置中。该框架与估计器无关，并可与 Kernel SHAP、Monte Carlo 和 Leverage SHAP 组合，且不改变其采样或加权性质。函数依赖进一步在特征联盟上诱导出等价类，RelShap 利用这些等价类在不改变 Shapley 值的情况下减少运行时间；我们给出了预期加速的组合刻画。在多个数据集、模型和估计器上的实验表明，RelShap 产生的解释更忠实于数据生成过程，在受控设置中能正确识别主导特征，而现有方法（包括 Conditional SHAP 和 ManifoldShap）则不能。我们的代码见：https://github.com/duneag2/relshap。

## Abstract
Machine learning pipelines commonly flatten relational data into single-table representations, discarding structural constraints. Widely used Shapley value-based feature attributions then rely on feature independence, evaluating the model on combinations that could never arise in the underlying data, producing misleading explanations. We propose RelShap, a framework that incorporates relational constraints and data provenance into Shapley value computation, restricting both background data and coalition evaluation to relationally valid configurations. The framework is estimator-agnostic and composes with Kernel SHAP, Monte Carlo, and Leverage SHAP without altering their sampling or weighting properties. Functional dependencies further induce equivalence classes over feature coalitions, which RelShap exploits to reduce runtime without changing Shapley values; we provide a combinatorial characterization of the expected speedup. Experiments across multiple datasets, models, and estimators show that RelShap produces explanations that are more faithful to the data-generating process, correctly identifying the dominant feature in controlled settings where existing methods, including Conditional SHAP and ManifoldShap, do not. Our code is available at: https://github.com/duneag2/relshap.

## 1. 核心问题与整体含义（研究动机和背景）

关系数据是许多 ML 应用的基础数据形态。然而，机器学习流水线通常将关系数据（多表、带主外键和约束）**扁平化为单表表示**用于模型训练，这一过程丢弃了数据库层面的结构信息，如函数依赖（FD）、域约束和否认约束。当训练好的模型需要做局部解释时，广泛使用的**基于 Shapley 值的特征归因方法**（如 Kernel SHAP）通常**假设特征相互独立**，会在关系上不可能出现的特征组合上评估模型，从而产生具有误导性的解释。

这个问题的本质是“**忠于模型还是忠于数据**”之间的张力：Kernel SHAP 忠于模型但忽略数据依赖结构；Conditional SHAP 试图估计条件分布但引入自身的建模误差。本文的核心论点是：在关系来源的数据上，这两种前提都有问题——扁平化丢弃的数据库约束恰恰决定了哪些组合是合理存在的，忽略这些约束会从根本上改变归因结果。

简言之，论文要回答的问题是：**如何在 Shapley 解释中系统地纳入关系约束，使解释忠于数据生成结构，同时不牺牲计算效率和与现有估计器的兼容性。**

## 2. 论文提出的方法论

### 2.1 核心思想

RelShap 的核心思路是：**改变 Shapley 解释自身的可容许空间**。具体而言，它把关系约束作为“可容许配置”的过滤器，同时限制两个关键维度：

- **背景数据选择**：缺失特征只能从满足关系约束的参考数据点中取值；
- **联盟选择**：只评估在关系约束下有效的特征子集。

### 2.2 关系约束的提取

RelShap 从三个来源提取关系约束，记为 $\Sigma_{\{S,Q,D\}} = \Sigma_{FD} \cup \Sigma_{dom} \cup \Sigma_{den}$：

- **关系模式（Schema）**：主键、唯一键、外键诱导的 FD，CHECK 子句等条件域约束；
- **查询（Query）**：通过 SQLGlot 解析 GROUP BY、窗口聚合、top-1 选择等查询结构，提取查询诱导的 FD 和域规则；
- **扁平化数据**：通过 FD 发现算法（左部大小上界默认 2）挖掘精确最小 FD，并从 FD 派生条件域规则和否认约束（如 one-hot 互斥、XOR 模式）。

### 2.3 关系一致的背景分布与联盟投影

**定义 1（关系一致的背景分布）**：

$$
P^{Rel}_{bg} =
\begin{cases}
P^{Marginal}_{bg}, & \text{若 } \Sigma = \emptyset \\[4pt]
\hat{P}\big(Z_{F \setminus S} \mid \tilde{x}(S, Z_{F \setminus S}) \models \Sigma\big), & \text{否则}
\end{cases}
$$

即当存在约束时，背景分布只把质量放在满足 $\Sigma$ 的补全上。

**定义 2（商空间联盟投影）**：定义联盟间的 $\Sigma$-等价关系 $S \sim_{\Sigma} S'$，当且仅当二者诱导出相同的关系有效补全集。将每个联盟映射到其等价类的规范代表，形成商空间 $C_{\Sigma}$。例如，若存在 FD $a \to b$，则 $\{a\} \sim \{a,b\}$，两类得以合并。

**命题 1（Shapley 值不变性）**：商空间联盟投影不改变所得 Shapley 值，对所有联盟估计器成立。这是因为等价联盟的边际贡献完全相同，只是通过缓存重用了计算。

### 2.4 溯源感知模式（Provenance-aware mode）

对于标识符被扁平化丢弃的场景，RelShap 通过**倒排索引和行集索引**追踪每行数据的来源元组。给定一个联盟，检查能否从已观察特征推断出唯一标识符：

- **Strict 模式**：仅在标识符被唯一确定时应用依赖；
- **Relaxed 模式**：当候选集内某属性值恒定时即可应用该依赖。

### 2.5 算法流程与运行时分析

**Algorithm 1** 的流程：从基础联盟分布中采样 $M$ 个原始联盟 → 若启用关系背景模式则做 FD 闭包规范化 → 若启用溯源模式则做溯源扩展 → 若启用完整性约束模式则做修复 → 在商空间中去重（缓存已评估的等价类）→ 返回规范化后的联盟集合。

**定理 1（商模式下的预期缩减）**：设 $q(C) = \Pr_{S \sim P_{coal}}([S]_{\Sigma} = C)$ 为采样联盟落入等价类 $C$ 的概率，则 $M$ 次独立采样后评估的不同类数期望为：

$$
\mathbb{E}[K_M] = \sum_{C \in C_{\Sigma}} \left(1 - (1 - q(C))^M\right),
$$

其中

$$
q(C) = \sum_{k=r(C)}^{|F|-1} p_k \frac{N_C(k)}{\binom{|F|-1}{k}},
$$

$N_C(k)$ 为投影到 $C$ 的大小为 $k$ 的联盟数，$r(C)$ 为类 $C$ 的最小生成联盟大小。归一化预期加速因子为 $R_M = 1 - \mathbb{E}[K_M]/M$。

### 3.3 对比的 RelShap 配置

- **BG**（关系背景模式，仅 FD）；
- **BG + DCs**（加域/否认约束）；
- **BG + Prov, Strict**（溯源严格模式）；
- **BG + Prov, Relaxed**（溯源宽松模式）；

### 3.4 受控真值实验

在受控设置中，定义合成预测器：

$$
g(x) = \mathbf{1}\{age > 50\} + \delta \cdot r(\text{life\_stage}) \cdot \mathbf{1}\{x \not\models \Sigma\},
$$

其中 $\delta$ 从 0 增至 10。数据中所有实例都满足约束，因此第二项仅在生成关系无效组合时被激活。真实有效域上的预测只取决于 age，直觉上正确的解释应赋予 age 更大的归因。

实验测量**违规普遍性**（violation prevalence）：Kernel SHAP 有 31.8%的联盟违反 FD，Conditional SHAP 和 ManifoldShap 分别有 4.8%和 5.1%，RelShap 为 0%。

## 6. 主要结论与发现

1. **在受控真值设置中，RelShap 是唯一正确的方法**：当违规扰动强度 $\delta$ 增大时，Kernel SHAP 将更多归因转移给 life_stage，Conditional SHAP 和 ManifoldShap 仍有部分实例排序错误，而 RelShap 在所有 $\delta$ 下始终正确识别主导特征 age，且归因向量完全不随 $\delta$ 变化。

2. **现实中不可能世界的普遍性很高**：常规 Shapley 计算在数据集上平均违规普遍性达到 64–74%（BG 约束下）到 82–93%（加入溯源约束后）。纳入更丰富的约束后，违规密度进一步提升。

3. **纠正效应是大且系统的**：排名差异（Top-3 Jaccard 距离、1−RBO）在多数配置和数据集上超出了随机扰动零基线。MC 估计器的变化最频繁，Leverage SHAP 次之，Kernel SHAP 相对最稳定。

4. **加速且不牺牲精确性**：商模式在 MC 和 Leverage SHAP 上始终降低运行时间（分别有 91.55%和 84.72%的案例减少），在 Kernel SHAP 上效果依赖 FD 结构。实测加速与定理 1 的组合预测高度相关（Pearson 均值 0.806，Kendall τ 均值 0.741）。

## 7. 优点

- **与估计器无关的可插拔设计**：RelShap 不修改现有估计器的采样分布、权重或精度保证，可作为限制层叠加使用。
- **同时处理三个层面的关系结构**：模式、查询、数据，且支持溯源感知，覆盖了从“仅扁平化数据可用”到“完整关系输入可用”的各种场景。
- **加速在数学上不改变 Shapley 值**：这是严格区别于“近似加速”的亮点，命题 1 确保商模式无偏，定理 1 给出组合刻画。
- **有真值受控验证**：通过受控合成实验直接验证了“排除不可能世界即改进关系有效性”的因果机制，而非仅凭语义直觉。
- **实验矩阵全面、开源**：覆盖多数据集、多模型、多估计器，并公开代码。

## 8. 不足与局限

- **缺乏人类判断验证**：论文明确承认，改进的验证仅建立在“关系有效性”和合成真值上，未能通过用户研究证明解释对人类决策者更有用、可信或可操作。
- **约束被视为正确**：RelShap 假定经用户审核后提取的约束都是真的。小数据集上发现的虚假 FD 会直接传播到解释中，未提供自动判断或概率化处理。
- **仅支持精确 FD**：实验全部使用精确 FD，不支持近似或带噪依赖。
- **Kernel SHAP 的加速不保证**：商模式在 Kernel SHAP 上的收益高度依赖 FD 结构，当 FD 左部规模较大时可能无收益甚至产生轻微开销。
- **域/否认约束带来额外开销**：DC 模式可能增加运行时（尤其 SpeedDating），说明完整性约束的修复逻辑尚未完全优化。
- **分布偏移未考虑**：论文未讨论训练分布与背景分布存在显著偏移的情形，默认二者对齐。
