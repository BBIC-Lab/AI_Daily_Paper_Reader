## 摘要
我们开发了自助法辅助的稳健二元分割（BARBS），这是一种在一般非平稳时间动态下进行多变点检测的递归二元分割方法。提出了一种新颖的针对CUSUM统计量的高斯乘子自助法，对复杂相依结构具有稳健性。通过在递归的每个阶段精细校准临界值，BARBS确保在无变点的原假设下控制第一类错误。当存在变点时，BARBS以预先指定的概率识别正确数量的变点，并且所得的变点位置估计量达到与经典二元分割相同的一致收敛速率。在此基础上，我们引入了第二阶段精化估计量，该估计量实现了最优的个体定位速率，并建立了在固定和消失跳跃幅度下的渐近分布以及近乎最优的一致定位速率。在各种设置下的大量数值实验证实了BARBS相对于现有方法的稳健性和优越性能。为说明所提出方法的实际相关性，我们分析了美国通货膨胀数据，得到的变点与若干有记录的宏观经济时期相吻合。

## Abstract
We develop bootstrap-assisted robust binary segmentation (BARBS), a recursive binary segmentation method for multiple change point detection under general nonstationary temporal dynamics. A novel Gaussian multiplier bootstrap for the CUSUM statistics is proposed, offering robustness to complex dependence structures. Through meticulous calibration of the critical values at each stage of the recursion, BARBS ensures control of the Type I error under the null hypothesis of no change points. When change points are present, BARBS identifies the correct number of changes with a prespecified probability, and the resulting change point location estimators attain the same uniform consistency rate as classical binary segmentation. Building on this, we introduce second-stage refined estimators that achieve the optimal individual localization rate, and establish their asymptotic distributions and nearly optimal uniform localization rates under both fixed and vanishing jump magnitudes. Extensive numerical experiments across various settings confirm the robustness and superior performance of BARBS relative to existing approaches. To illustrate the practical relevance of the proposed methodology, we analyze U.S. inflation data, yielding change points that align with several documented macroeconomic episodes.

## 二、方法论

### 2.1 模型与非平稳误差刻画

- 误差过程采用物理依赖度量框架：  
  $$\varepsilon_i = G_i(\mathcal{F}_i),$$  
  其中 $G_i$ 可随时间变化，$\mathcal{F}_i=(..., e_{i-1}, e_i)$ 由 i.i.d. 随机变量生成。
- 依赖度量定义为  
  $$\delta_{k,q} = \max_{1\le i\le n} \lVert G_i(\mathcal{F}_i) - G_i(\mathcal{F}_{i,i-k}) \rVert_q,$$  
  用于刻画滞后 $k$ 的创新对当前观测的均匀影响。
- 特别地，允许**分段局部平稳（PLS）噪声**，即误差机制在不同时间段可能发生突变，段内平滑变化。

### 2.2 CUSUM 统计量与高斯乘子 bootstrap

- 对区间 $[s,e]$，定义标准 CUSUM 统计量：  
  $$T_{s:e,m} = \max_{s+m \le k \le e-m} \lvert S_{s,k,e} \rvert,$$  
  其中  
  $$S_{s,k,e} = \frac{1}{\sqrt{e-s+1}} \left(\sum_{i=s}^{k} X_i - \frac{k-s+1}{e-s+1}\sum_{i=s}^{e} X_i\right).$$
- 为避免依赖平稳极限分布，提出**高斯乘子 bootstrap**：
  - 对区间内每个位置 $j$ 构造局部差分：  
    $$Y_j = \frac{1}{\sqrt{2m}} \left(\sum_{i=j-m+1}^{j} X_i - \sum_{i=j+1}^{j+m} X_i\right).$$
  - 生成 i.i.d. 标准正态随机乘子 $G_j^{(b)}$，构造 bootstrap 版本  
    $$S_{s,k,e}^{(b)} = \frac{1}{\sqrt{e-s-2m+1}} \left(\sum_{j=s+m}^{k} Y_j G_j^{(b)} - \frac{k-s-m+1}{e-s-2m+1}\sum_{j=s+m}^{e-m} Y_j G_j^{(b)}\right),$$  
    并取最大值 $T_{s:e,m}^{(b)}$。
  - 以 $B$ 次 bootstrap 样本的经验 $(1-\tilde{\alpha})$ 分位数作为临界值。

### 2.3 BARBS 递归算法

- 将全局显著性水平 $\alpha$ 按区间长度分配到各次检验：  
  $$\tilde{\alpha} = \frac{e-s+1}{n}\alpha.$$
- 若 $T_{s:e,m}$ 超过 bootstrap 临界值，则用加权 CUSUM 估计变点：  
  $$\hat{k}_{s:e} = \arg\max_{s+m \le k \le e-m} \sqrt{\frac{(e-s+1)^2}{(k-s+1)(e-k)}} \lvert S_{s,k,e} \rvert.$$
- 对变点左、右子区间递归执行上述步骤，直至不再拒绝原假设或区间长度小于最小长度 $L=2m+1$。
- 输出有序变点集合 $\hat{k}_1 < \cdots < \hat{k}_{\hat{r}_n}$。

### 2.4 第二阶段精化估计与置信区间

- 在初估变点基础上，对第 $l$ 个变点在相邻初估变点之间重新做局部 CUSUM：  
  $$\tilde{k}_l = \arg\max_{\hat{k}_{l-1}+m \le k \le \hat{k}_{l+1}-m} \left| \sum_{i=\hat{k}_{l-1}+1}^{k} X_i - \frac{k-\hat{k}_{l-1}}{\hat{k}_{l+1}-\hat{k}_{l-1}} \sum_{i=\hat{k}_{l-1}+1}^{\hat{k}_{l+1}} X_i \right|.$$
- 在跳跃幅度 $\Delta_l$ 固定时，$\tilde{k}_l - k_l^*$ 的渐近分布依赖误差联合分布；在 $\Delta_l\to 0$ 且误差为 PLS、长方差在变点处连续时，可得：  
  $$\frac{\Delta_l^2}{\sigma^2(\tau_l)}(\tilde{k}_l - k_l^*) \overset{d}{\longrightarrow} \arg\max_{t\in\mathbb{R}}\{W(t) - |t| m_l(t)\},$$  
  其中 $W(t)$ 为双侧 Wiener 过程，$\sigma^2(\tau_l)$ 为局部长期方差。
- 基于该极限分布构造变点位置的渐近置信区间。
