## 摘要
状态空间模型（SSMs）作为线性Transformer的主流研究方向之一，旨在在长上下文建模中实现比标准Transformer更高的效率。然而，现有SSMs存在输入自适应性有限和记忆容量受限的问题，导致在建模超长序列时信息丢失。为解决这些局限性，我们提出了MixFormer，一种集成了记忆专家混合（MoE）机制的新型线性Transformer。具体而言，该模型通过多个协作的记忆专家维护差异化的记忆状态，并采用一种新颖的时间感知线性注意力（TALA）机制，该机制利用可学习的指数衰减函数和位置偏置来动态更新记忆。该设计使模型能够选择性地强化重要历史信息，同时有效缓解记忆稀释，从而显著提升长程依赖建模能力。在长序列文本和图像生成任务上的实验表明，MixFormer不仅取得了显著的性能提升，还为下一代网络基础设施提供了更具可持续性的计算骨干。

## Abstract
State Space Models (SSMs), as a mainstream research direction of linear Transformers, aim to achieve higher efficiency than standard Transformers in long-context modeling. However, existing SSMs suffer from limited input adaptivity and constrained memory capacity, leading to information loss when modeling ultra-long sequences. To address these limitations, we propose MixFormer, a novel linear Transformer that integrates a Mixture-of-Memory-Experts (MoE) mechanism. Specifically, the model maintains differentiated memory states through multiple collaborating memory experts and employs a novel Time-Aware Linear Attention (TALA) mechanism, which leverages learnable exponential decay functions and positional biases to dynamically update memory. This design enables the model to selectively reinforce important historical information while effectively mitigating memory dilution, substantially improving long-range dependency modeling. Experiments on long-sequence text and image generation tasks demonstrate that MixFormer not only achieves significant performance gains but also provides a more sustainable computational backbone for the next generation of web infrastructure.

## 2. 论文提出的方法论

### 2.1 总体架构

MixFormer 采用类似标准 Transformer 的堆叠结构，每个 MixFormer block 包含：

- 时间感知线性注意力层（TALA）；
- 前馈网络（FFN）；
- 每个子层前使用 Group Normalization（GN），并采用残差连接。

输入 $X$ 经过嵌入后得到初始表示 $X^0\in\mathbb{R}^{n\times d}$，再通过 $L$ 个 block 逐层优化：

$$ X^l = \text{MixFormerBlock}_l(X^{l-1}),\quad l=1,\dots,L $$

每个 block 的计算为：

$$ Y^l = \text{TALA}(\text{GN}(X^l)) + X^l,\quad X^{l+1}=\text{FFN}(\text{GN}(Y^l))+Y^l $$

### 2.2 时间感知线性注意力（TALA）

TALA 替代标准多头自注意力，支持**并行训练、递归推理和分块递归**三种模式。

- **投影与核函数**：对输入进行投影：

  $$ Q = XW_Q,\quad K = XW_K,\quad V = XW_V $$

  为保证非负性，对 $Q$、$K$ 应用核函数变换：

  $$ \phi(Q)=e^{\frac{Q}{\|Q\|}},\quad \phi(K)=e^{\frac{K}{\|K\|}} $$

  其中 $\|\cdot\|$ 为行/列向量 $L_2$ 归一化。

- **时间衰减与位置偏置**：TALA 在 KV 对上引入指数衰减权重和可学习的位置偏置 $G$，利用相对位置信息强调近期信息，同时进行维度级自适应校准。核心注意力公式为：

  $$ \text{TALA}_t(Q_t,K_t,V_t)=\phi(Q_t)\odot\frac{\sum_{i=1}^{t}\phi(K_i)(\omega G_i)^{t-i}V_i}{\sum_{i=1}^{t}\phi(K_i)(\omega G_i)^{t-i}} $$

  其中 $\omega$ 为指数衰减权重，$G\in\mathbb{R}^{T\times T}$ 为可学习的两两位置偏置。

- **多头扩展**：将隐藏维度 $d$ 分割为多个头，每个头分配独立的衰减参数 $\omega$，以多尺度捕捉时序动态。

- **三种计算形式**：
  - **并行表示**：训练时使用矩阵运算加速：

    $$ \text{TALA}(Q,K,V)=Q\odot(K^\top \odot D)V $$

    其中因果掩码矩阵 $D$ 定义为：

    $$ D_{nm}=
    \begin{cases}
    \omega^{n-m}G_{nm}, & n\ge m\\[2pt]
    0, & n<m
    \end{cases} $$

  - **递归表示**：推理时维护固定尺寸记忆状态，保证 $O(1)$ 内存：

    $$ S_0=0,\quad S_n=\omega G\odot S_{n-1}+K_n^\top V_n,\quad O_n=Q_n S_n $$

  - **分块递归表示**：将序列分成长度为 $B$ 的块，块内并行、块间递归，兼顾训练效率与硬件友好性。

### 2.3 混合记忆专家机制（MoME）

为突破单一记忆状态的容量限制，MoME 部署多个功能异质的记忆专家，根据当前上下文动态激活最相关的专家，并对多个记忆状态进行加权聚合：

$$ Y_{ms}=\sum_{i=1}^{n}E_i\,MS_i $$

其中 $MS_i$ 为第 $i$ 个记忆专家，$E_i$ 为路由器权重：

$$ E_i=\text{Softmax}(K_n V_n W_g),\quad \sum_{j=1}^{k_e}E_{ji}=1 $$

$W_g\in\mathbb{R}^{1\times k_e}$ 为可学习参数，$k_e$ 为专家数量。不同专家可专门处理短时特征提取或长程依赖保持，通过多粒度记忆保存策略实现关键信息的长期留存。

### 2.4 复杂度分析

MixFormer 总计算成本由投影、TALA、MoME 和 FFN 组成：

$$ 4Nd^2 + Nd^2 + Nk + 2dd' $$

在长序列情形下（$N\gg d$），整体复杂度收敛为 $O(N)$，推理时单 token 成本为 $O(1)$。
