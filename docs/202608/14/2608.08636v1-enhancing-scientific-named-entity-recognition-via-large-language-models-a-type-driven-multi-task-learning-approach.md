## 摘要
科学命名实体识别（SciNER）在科学文本的信息抽取和知识发现中起着关键作用。近年来，大语言模型（LLMs）已展现出在极少人工干预下取得有竞争力的SciNER性能的能力。现有研究强调了纳入候选实体类型信息对LLMs准确识别和分类实体的重要性。然而，当提示中提供过多候选实体类型时，LLMs难以准确识别和标注科学文本中的实体，而科学领域的实体类型比通用领域更为复杂。为应对这一挑战，我们提出TdSciNER，一种有效利用实体类型信息来提升SciNER性能的类型驱动方法。在TdSciNER中，我们首先设计了一个实体类型过滤模型，以识别给定句子中最可能出现的实体类型。随后，在多任务学习框架中引入一个辅助的多分类实体类型标注任务，与SciNER一起学习以获得更丰富的上下文表示。接着，我们提出了一种基于句子相似度和实体类型多样性的新颖示例选择策略，激活LLMs的上下文学习能力，从而提高跨不同科学领域的实体识别准确率。在三个数据集上的实验表明，我们的方法取得了与全监督模型相当的性能。进一步分析验证了TdSciNER中每个由实体类型驱动的组件都有助于SciNER性能的提升。该工作为未来SciNER及科学文本挖掘中更广泛的信息抽取任务的发展提供了有价值的见解。

## Abstract
Scientific named entity recognition (SciNER) plays a crucial role in information extraction and knowledge discovery from scientific texts. Recently, large language models (LLMs) have demonstrated the capacity to achieve competitive SciNER performance with minimal human effort. Existing research highlights the importance of incorporating candidate entity type information for accurate entity recognition and classification by LLMs. However, when too many candidate entity types are provided in the prompt, LLMs struggle to accurately recognize and label entities in scientific texts, where entity types are more complex than in general domains. To address this challenge, we propose TdSciNER, a type-driven approach that effectively leverages entity type information to enhance SciNER performance. In TdSciNER, we first design an entity type filter model to identify the most likely entity types present in a given sentence. Subsequently, we introduce an auxiliary multi-class entity typing task within a multi-task learning framework alongside SciNER to obtain richer contextual representations. Then, we develop a novel demonstration selection strategy based on sentence similarity and entity type diversity to activate the in-context learning capabilities of LLMs, thereby improving entity recognition accuracy across diverse scientific domains. Experiments on three datasets demonstrate that our method achieves performance comparable to fully supervised models. Further analysis validates that each entity type-driven component in TdSciNER contributes to the improvement of SciNER performance. This work provides valuable insights for future advancements in SciNER and broader information extraction tasks in scientific text mining.

## 2. 论文提出的方法论

- **总体框架**：TdSciNER 包括三个类型驱动组件：
  1. **实体类型过滤器（Entity Type Filter, ETF）**：估计句子中可能出现的实体类型，过滤不相关类型。
  2. **辅助实体类型标注任务（Auxiliary Entity Typing Task）**：与主 SciNER 任务多任务联合训练。
  3. **相似度-多样性均衡的演示选择策略**：为 ICL 选择高质量少样本示例。

- **任务形式化**：
  - 给定输入科学文本 $x$ 和指令 $I$，完整提示为 $\text{Prompt}=I \oplus x$。
  - LLM 生成输出序列 $y$，解析为实体-类型对集合 $T=\{(c_1,e_1),\dots,(c_n,e_n)\}$。
  - 生成过程建模为条件概率分布  
    $$p(y\mid x,I)=\prod_{t=1}^{L} p(y_t\mid y_{<t},x,I)$$
  - 主任务采用负对数似然损失  
    $$\mathcal{L}_{SciNER}=-\sum_{t=1}^{L}\log p(y_t\mid y_{<t},x,I)$$

- **实体类型过滤器**：
  - 用 GPT-4 为每个候选实体类型生成领域化描述，得到描述集合 $D=\{d_{c_1},\dots,d_{c_n}\}$。
  - 从训练集中抽取只包含单一实体类型的句子子集 $S=\{S_{c_1},\dots,S_{c_n}\}$。
  - 用 BERT 类编码器将输入句子 $x$ 编码为 $h_x$。
  - 计算输入与类型描述、输入与类型示例集之间的余弦相似度，加权融合得到最终相似度  
    $$f_{filter}=w\cdot f_{filter}(h_x,d_{c_i})+(1-w)\cdot f_{filter}(h_x,S_{c_i})$$
  - 设置阈值 $\delta$，仅保留相似度高于阈值的候选类型集合 $C'$。
  - 微调编码器时使用对比损失  
    $$\mathcal{L}_{ETF}=-\sum_{t_p\in P_x}\log\frac{e^{sim(h_x,t_p)/\tau}}{\sum_{t\in P_x\cup N_x} e^{sim(h_x,t)/\tau}}$$
    其中 $P_x$ 和 $N_x$ 分别是句子中出现的正类型和未出现的负类型，$\tau$ 为温度参数。

- **辅助多任务学习**：
  - 对每个已标注实体 $e_i$，模型从候选类型集合 $C$ 中预测其类型，输出概率分布 $\hat{p}_i$。
  - 使用交叉熵损失  
    $$\mathcal{L}_{Entity\_typing}=-\sum_{c\in C} y_{i,c}\log(\hat{p}_{i,c})$$
  - 总损失为  
    $$\mathcal{L}=\mathcal{L}_{SciNER}+\lambda\mathcal{L}_{Entity\_typing}$$
  - 该辅助任务复用现有标注，不增加额外标注成本。

- **演示选择策略**：
  - 构造候选示例集合 $K_{candidate}$。
  - 对每个候选 $k_i$，计算与输入 $x$ 的余弦相似度 $\mathrm{Sim}(x,k_i)$，以及实体类型多样性得分 $\mathrm{div}_{type}(k_i)$。
  - 通过句法解析树和树编辑距离计算结构多样性  
    $$\mathrm{div}_{structure}(x,k_i)=\frac{\mathrm{TED}(x,k_i)}{\max(|x|,|k_i|)}$$
  - 综合排序  
    $$\mathrm{ICL}_{topk}=\alpha\cdot \mathrm{Sim}(x,k_i)+\beta\cdot \mathrm{div}_{type}(x,k_i)+\gamma\cdot \mathrm{div}_{structure}(x,k_i)$$
  - 选择前 $k$ 个作为少样本提示示例。

## 6. 论文的主要结论与发现

- TdSciNER 在 SciERC 和 JNLPBA 上取得最高 F1（70.58%、79.34%），在 BC5CDR 上取得 89.83%，整体达到与全监督基线相当的水平。
- 实体类型过滤器能有效缩小候选类型空间，去除不相关类型后 F1 分别提升 2.26、2.81、0.41 个百分点。
- 辅助实体类型标注任务无需额外标注即可丰富上下文表示，对类型更多的数据集收益更大。
- ICL 演示选择中，同时考虑句子相似度、实体类型多样性和结构多样性可获得最佳效果；最佳权重约为相似度 0.4、类型多样性 0.4、结构多样性 0.2。
- 对未见领域，若无验证集，过滤阈值 $\delta\approx0.65$ 可作为合理默认值。
- 领域特定编码器（SciBERT、BioBERT）在对应领域上的过滤效果优于通用编码器。
