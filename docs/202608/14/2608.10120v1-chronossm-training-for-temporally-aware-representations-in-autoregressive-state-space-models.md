## 摘要
现代序列模型，从 Transformers 到状态空间模型，已在多个领域实现了强大的生成建模，但它们通常被训练来预测发生什么，而将何时发生视为次要问题。在事件与显式时间信息相关联的数据挖掘场景中，这种分离可能限制时间推理、异常检测以及事件时间顺序的忠实重建。一种常见策略是将时间信息作为辅助信号，使用仅为事件预测学习的表示训练单独的时间模型。然而，这种两阶段方法隐含地假设针对事件预测优化的表示已包含足够的时间结构。我们引入了 ChronoSSM，这是一种自回归状态空间模型（SSM），它通过共享骨干网络联合建模事件和时间戳，并使用组合的 token 生成目标与时间生成目标进行训练。我们比较了联合训练机制（时间监督更新骨干网络）与两阶段机制（仅使用冻结的事件表示学习时间信息）。在涵盖密集和部分时间戳监督的四个领域中，联合训练一致地使得到达间隔信息从冻结表示中更易恢复，且整体上内容生成质量没有系统性下降。我们的结果表明，时间监督可以产生更具时间信息量的表示，而不会对自回归事件建模造成实质性损害。

## Abstract
Modern sequence models, from Transformers to State Space Models, have enabled powerful generative modeling across diverse domains, yet they are typically trained to predict what happens while treating when it happens as a secondary concern. In data-mining settings where events are associated with explicit timing information, this separation can limit temporal reasoning, anomaly detection, and faithful reconstruction of event chronology. A common strategy is to treat timing as an auxiliary signal, training a separate timing model using representations learned solely for event prediction. However, this two-stage approach implicitly assumes that representations optimized for event prediction already contain sufficient temporal structure.   We introduce ChronoSSM, an autoregressive State Space Model (SSM) that jointly models events and timestamps with a shared backbone trained using combined token and temporal generation objectives. We compare the joint regime, where temporal supervision updates the backbone, with the two-stage regime, where timing is learned only using the frozen event representations. Across four domains spanning dense and partial timestamp supervision, joint training consistently makes inter-arrival information more recoverable from frozen representations without any systematic degradation in content-generation quality overall. Our results show that temporal supervision can produce more temporally informative representations without materially degrading autoregressive event modeling.

- **研究动机**：现代序列模型（如 Transformer、状态空间模型）在事件序列建模中通常只优化“发生了什么”（next-token prediction），而把“何时发生”（timestamp / inter-arrival time）当作次要信号或后处理任务。
- **现有做法的局限**：常见两阶段策略先训练事件预测模型，再冻结其表示训练单独的时间预测头。这种做法隐含假设“仅为事件预测优化的表示已经包含足够时间结构”，但该假设未必成立。
- **整体目标**：论文提出 ChronoSSM，一种自回归状态空间模型，让事件身份与事件时间在共享骨干网络中联合学习，从而在不牺牲内容生成质量的前提下，学习更具时间信息量的表示。

## 2. 方法论

### 2.1 问题形式化

- 给定时间戳序列 $\{(x_k, t_k)\}_{k=0}^{T-1}$，其中 $x_k$ 为离散 token，$t_k$ 为对应时间戳。
- 到达间隔时间为 $\Delta t_k = t_k - t_{k-1}$。
- 目标是建模联合分布：
  $$p_\gamma(x_{k+1}, \Delta t_{k+1} \mid X_k) = p_{\theta,\alpha}(x_{k+1}\mid X_k)\, p_{\theta,\phi}(\Delta t_{k+1}\mid x_{k+1}, X_k)$$
  其中 $X_k$ 为 token 历史，$\gamma=\{\theta,\alpha,\phi\}$ 分别为共享骨干、token 预测头、时间预测头的参数。

### 2.2 ChronoSSM 模型设计

- **共享骨干**：因果自回归模型，论文主实验使用 Mamba2。第 $k$ 步产生隐藏状态 $h_k$。
- **token 预测头**：线性映射 $W^{tok}_\alpha \in \mathbb{R}^{V\times D}$，输出 softmax 分布。
- **时间预测头**：使用相邻隐藏状态之差作为时间表示：
  $$r_{k+1} = \Delta h_{k+1} = h_{k+1} - h_k$$
  与时间差 $\Delta t_{k+1}=t_{k+1}-t_k$ 形成结构对应。
- **时间目标变换**：对密集时间戳数据，使用 $z_k=\log(1+\Delta t_k/s)$ 避免零值和长尾问题；时间头输出经 softplus 映射为非负预测，再同样变换为 $\hat z_k$。
- **时间损失**：采用固定方差 log-normal 密度，其负对数似然等价于 $\hat z_k$ 与 $z_k$ 的平方误差，形式简单。

### 2.3 训练目标与两种训练机制

- 总损失：
  $$\mathcal{L} = \mathcal{L}_{tok} + \lambda_\tau \mathcal{L}_{time}$$
  其中 $\mathcal{L}_{tok}$ 是 token 交叉熵，$\mathcal{L}_{time}$ 是时间预测平方误差，$\lambda_\tau$ 控制时间监督权重。
- **Joint 训练**：时间梯度同时更新共享骨干、token 头和时间头，使骨干表示被迫编码时间结构。
- **Two-Stage 训练**：第一阶段仅用 $\mathcal{L}_{tok}$ 训练骨干和 token 头；第二阶段冻结骨干，仅训练时间头。时间梯度不能修改骨干表示。
- 两种机制使用相同架构、数据、时间目标与生成过程，仅“时间损失是否更新骨干”不同，构成控制比较。

### 2.4 推断流程

- 给定历史，先由 token 头预测下一个 token $x_{k+1}$。
- 骨干处理该 token 后得到 $h_{k+1}$，计算 $\Delta h_{k+1}$。
- 时间头由 $\Delta h_{k+1}$ 预测到达间隔 $\widehat{\Delta t}_{k+1}$，并更新 $t_{k+1}=t_k+\widehat{\Delta t}_{k+1}$。
