## 摘要
机制可解释性最近已扩展到视觉Transformer（ViT），稀疏自编码器（SAE）越来越多地被用作事后工具，将内部表征分解为稀疏且更可解释的特征。然而，由于事后SAE是在ViT优化完成后基于冻结表征进行训练的，其潜在特征并未与下游分类目标直接对齐。我们提出SpIn-ViT框架，该框架端到端地联合训练一个预训练ViT和一个修改后的SAE，直接将稀疏的块级（patch-level）表征与图像分类对齐。SpIn-ViT学习语义连贯的神经元激活，能够定位有意义的图像区域，同时保持有竞争力的预测性能。我们在九个图像分类基准上评估SpIn-ViT，使用分类准确率、定量可解释性指标、基于AI的评估和人工评估。与此前最先进的事后SAE方法相比，SpIn-ViT的平均分类准确率提高了8.84%，基于AI的可解释性得分接近其四倍，人工评估得分超过其两倍。我们进一步利用SAE神经元提取可解释的规则集，构建神经符号模型，这些模型的平均分类准确率比由最先进事后SAE方法构建的神经符号模型高出5.97%，同时所需规则集规模减小58.8%。

## Abstract
Mechanistic interpretability has recently expanded to Vision Transformers (ViTs), with Sparse Autoencoders (SAEs) increasingly used as post-hoc tools to decompose internal representations into sparse and more interpretable features. However, because post-hoc SAEs are trained on frozen representations after the ViT has already been optimized, their latent features are not directly aligned with the downstream classification objective. We introduce SpIn-ViT, a framework that jointly trains a pretrained ViT and a modified SAE end-to-end, directly aligning sparse patch-level representations with image classification. SpIn-ViT learns semantically coherent neuron activations that localize meaningful image regions while maintaining competitive predictive performance. We evaluate SpIn-ViT across nine image-classification benchmarks using classification accuracy, quantitative interpretability metrics, AI-based and Human evaluations. Compared with the previous state-of-the-art post-hoc SAE method, SpIn-ViT achieves 8.84% higher average classification accuracy, an AI-based interpretability score nearly four times as high, and a human-evaluation score more than twice as high. We further extract interpretable rule-sets using the SAE neurons to create neurosymbolic models which achieve 5.97% higher average classification accuracy while requiring a 58.8\% smaller rule-set than the neurosymbolic models created from the SOTA post-hoc SAE method.

## 2. 方法论

### 2.1 总体架构

SpIn-ViT 的核心做法是：将 ViT 最后一层得到的 patch token 表征送入 SAE，编码为更高维、稀疏的潜在向量，再由 SAE 解码器重构原始 patch 嵌入；分类仍由 [CLS] token 经线性头完成。

设 ViT 输出 patch 表征为 $z = [z_1, z_2, \dots, z_n] \in \mathbb{R}^{n \times d}$，其中 $d = 768$。SAE 编码与解码过程为：

$$
h = \mathrm{TopK}(z W_{enc} + b_{enc})
$$

$$
\hat{z} = h W_{dec} + b_{dec}
$$

其中：
- $W_{enc} \in \mathbb{R}^{d \times m}$，$m = 10 \times C$，$C$ 为类别数；
- $\mathrm{TopK}$ 对每个 patch token 独立保留前 $k$ 大的激活，其余置零；
- $W_{dec} \in \mathbb{R}^{m \times d}$ 用于重构原始 patch 嵌入。

$\mathrm{TopK}$ 固定每个 patch 的活跃神经元数量，避免过密表示；它与后面提到的 $L_1$ 正则共同促进稀疏、语义上可分离的特征。

### 2.2 损失函数设计

SpIn-ViT 使用四个互补目标，总损失为：

$$
L = \alpha L_{cls} + \beta L_{SAE} + \delta L_{center} + \gamma L_{ortho}
$$

其中权重设置为 $\alpha = 1$、$\beta = 1$、$\delta = 0.3$、$\gamma = 2.0$。

#### （1）分类目标 $L_{cls}$

使用标准交叉熵损失：

$$
L_{cls} = -\frac{1}{B} \sum_{i=1}^{B} \sum_{c=1}^{C} y_{i,c} \log p_{i,c}
$$

其中 $y_{i,c}$ 为真实标签指示，$p_i = \mathrm{softmax}(f_\theta(X_i))$ 为预测概率。分类头作用于最终 [CLS] token 表示。

#### （2）可解释性 / SAE 目标 $L_{SAE}$

由重构损失与稀疏损失组成：

$$
L_{SAE} = \underbrace{\frac{1}{B} \sum_{i=1}^{B} \| z_i - \hat{z}_i \|_F^2}_{L_{recon}} + \lambda \underbrace{\frac{1}{B} \sum_{i=1}^{B} \| h_i \|_1}_{L_{sparse}}
$$

- $L_{recon}$ 保持 SAE 对原始 ViT patch 表征的重构能力；
- $L_{sparse}$ 对 TopK 保留的激活幅度进行 $L_1$ 惩罚；
- $\lambda = 5 \times 10^{-4}$。

#### （3）类内目标 $L_{center}$

使用中心损失，使同类样本的平均池化重构表示靠近其类中心：

$$
L_{center} = \frac{1}{2B} \sum_{i=1}^{B} \| p_i - c_{y_i} \|_2^2
$$

其中 $p_i$ 是对重构 patch 嵌入 $\hat{z}_i$ 沿 patch 维度做平均池化得到的向量，$c_{y_i}$ 是类别 $y_i$ 的中心。梯度会通过 SAE 与 ViT 回传，促使潜在表示与类别信息对齐。

#### （4）类间目标 $L_{ortho}$

将 SAE 潜在空间维度 $m$ 划分为 $C$ 个不重叠的、按类别索引的块，每个块维度 $r = m/C$。对每个块 $S^{(c)} \in \mathbb{R}^{Bn \times r}$，施加正交正则：

$$
L_{ortho} = \frac{1}{C} \sum_{c=1}^{C} \left\| (S^{(c)})^\top S^{(c)} - I_r \right\|_F^2
$$

目的是减少同一类子空间内不同潜在神经元之间的冗余，增强特征多样性。

### 2.3 可解释性分析流程

训练完成后，通过以下步骤定量与定性评估神经元语义：

- **参考图像选择**：对每个 latent 神经元，计算图像级聚合激活：

$$
p^{(i)}_{patch} = \frac{1}{n} \sum_{j=1}^{n} h_{i,j}
$$

按该值对所有图像排序，取最强响应的前 $K_{ref}$ 张作为参考图像。

- **patch 分割**：对神经元 $q$ 在图像 $i$ 的 patch $j$ 的激活 $h_{i,j,q}$，先经 Sigmoid 映射到 $[0,1]$，再以阈值 $\tau = 0.5$ 二值化：

$$
\tilde{h}_{i,j,q} = \sigma(h_{i,j,q})
$$

$$
A^{(q)}_{i,j} =
\begin{cases}
1, & \tilde{h}_{i,j,q} > 0.5 \\
0, & \text{otherwise}
\end{cases}
$$

分割图 $S^{(q)}_{i,j} = A^{(q)}_{i,j} \odot X_{i,j}$，即保留神经元关注的原图像 patch。

- **插入 / 删除（Insertion / Deletion）**：按连续激活得分对 patch 排序，逐步插入或删除最相关 patch，观察分类置信度变化。插入越快上升、删除越快下降，说明归因越忠实于模型预测。

### 2.4 神经符号规则提取

- 对每个图像，将 SAE 激活沿 patch 维度平均池化，得到特征向量 $p_i \in \mathbb{R}^m$；
- 经 Sigmoid 与阈值 0.5 二值化，得到每个神经元对应谓词的真假值；
- 将二值特征作为表格数据，使用 **FOLD-SE-M** 算法诱导分层 Answer Set Program（ASP）规则；
- 最终由 ViT + SAE 特征提取器与 ASP 规则集组成神经符号分类器。

例如规则可以是：

```
label(X, 'Truck') :- neuron_63(X), not ab1(X).
```

其中 `neuron_63` 对应真实 SAE 神经元，可通过 patch 激活图解释其视觉语义。
