## 摘要
在临床护理、工业运营、金融服务和物流等监控应用中，对长上下文时间序列进行精确异常定位是一项关键任务，其中短暂的证据可能隐藏在高频数据的长跨度中。时序语言模型（TSLM）能够摄取时间序列数据，并用自然语言描述异常发现；然而，最近的基准测试报告显示，在长上下文场景下检索性能会下降，这反映了文本、视觉和音频领域的失效模式。在文本领域，递归语言模型（RLM）通过将上下文保留在大型语言模型（LLM）之外，使模型能够通过代码查询上下文，从而可以恢复大部分性能损失。我们提出了 TimeRLM，这是一种针对时间序列的 RLM 形式化方法，它利用代码和视觉能力顺序地处理信号。我们还引入了 AnomalyXL，一个合成的长上下文异常定位基准测试，其中包含需要精确检索的程序化注入异常。我们实现了五个不同的任务类别和两个变体：AnomalyXL-MCQ 和 AnomalyXL-Localize。TimeRLM 在五个 AnomalyXL-Localize 任务中的四个上优于所有评估过的 TSLM 和单次通过的基线模型，在定位任务上的 IoU 达到 0.682，在带证据分类任务上达到 0.745，而所有基线模型的最高值分别为 0.329 和 0.072。我们使用强化学习对 TimeRLM 进行后训练。由此产生的模型进一步提升了性能，并且产生最终答案所需的智能体交互轮次大约是其未训练基础模型的三分之一。在未见过的真实世界心电图、睡眠和软件可观测性记录上，后训练的 TimeRLM 保持或提高了性能，尽管完全在合成数据上训练，却超越了 TSLM。我们的研究结果表明，与时间序列的递归交互是一种有效的长范围检索方法。

## Abstract
Precise anomaly localization over long-context time series is a crucial task in monitoring applications across clinical care, industrial operations, financial services, and logistics, where brief evidence may hide inside long spans of high-frequency data. Time-Series Language Models (TSLMs) are able to ingest time series data and verbalize findings on anomalies in natural language; however, recent benchmarks report a decrease in retrieval performance at long contexts, mirroring failure modes in text, vision, and audio. In the text domain, Recursive Language Models (RLMs) can recover much of this lost performance by keeping context external to the large language model (LLM), allowing the model to query it through code. We present TimeRLM, an RLM formulation for time-series that sequentially manipulates the signal using code and vision capabilities. We further introduce AnomalyXL, a synthetic long-context anomaly localization benchmark with programmatically injected anomalies that require precise retrieval. We implement five different task categories and two variants: AnomalyXL-MCQ and AnomalyXL-Localize. TimeRLM outperforms every evaluated TSLM and single-pass baseline on four of the five AnomalyXL-Localize tasks, reaching 0.682 IoU on localization and 0.745 on classify-with-evidence, versus at most 0.329 and 0.072 across all baselines. We post-train TimeRLM using reinforcement learning. The resulting model further improves performance and requires approximately one-third as many agent interaction turns as its untrained base model to produce a final answer. On unseen real-world ECG, sleep and software observability recordings, the post-trained TimeRLM retains or improves performance, surpassing TSLMs despite being trained exclusively on synthetic data. Our findings suggest recursive interaction with time-series is an effective approach for long-horizon retrieval.

### 2. 方法论

#### 2.1 TimeRLM 的核心思想
将时间序列视为 **外部上下文变量**（不在 LLM 输入 prompt 中展开），LLM 在沙盒 Python 环境中通过多轮交互（调用代码库 `numpy`, `scipy`, `matplotlib` 等）逐步分析信号。每个回合可执行代码观察结果，也可递归地调用“子‑RLM”处理信号片段，最终提交一个结构化 JSON 答案。

- **决策过程形式化**（第 3.1 节）  
  将精确异常定位建模为有限阶段的序贯决策过程：  
  - 状态 $s_t = (X, q, h_t)$：信号 $X \in \mathbb{R}^{C \times L}$、问题 $q$ 和历史交互 $h_t$；  
  - 动作空间 $A = \mathcal{C} \cup \{\mathrm{FINAL}(\hat{y})\}$，可执行代码 $c\in\mathcal{C}$ 或提交最终答案；  
  - 执行代码返回观察 $o_t = \mathrm{exec}(c_t, s_t)$，事件链终止于 $\mathrm{FINAL}$，获得单一可验证奖励 $r(\hat{y}, y) \in [0,1]$。  
  单次通过（Single‑pass）是 $N=1$ 且 $A=\{\mathrm{FINAL}(\hat{y})\}$ 的特例。

- **模态与递归**  
  - **文本模式**：仅通过代码处理数值序列。  
  - **图像模式**：沙盒中可渲染信号为图片并通过视觉能力感知。  
  - **子‑RLM 调用**：允许深度‑1 递归（本文多数实验未启用递归，仅在部分最优配置中启用）。

#### 2.2 基准 AnomalyXL 的构建
合成生成长上下文、多通道时间序列，异常以程序化方式注入，要求精确检索位置、类型、幅度等。

- **信号生成**：基信号由白噪声 / 红噪声 / AR(1) + 可选周期分量 + 趋势分量构成，每通道 z‑标准化。
- **异常注入**：五种类型——水平偏移（Level Shift）、瞬态尖峰（Transient Spike）、季节变化、方差变化、趋势变化，作用在窗口 $[s,e)$ 上，幅度以信道标准差 $\sigma$ 为单位，窗口宽度 8–256 个点，序列长度 16k–131k 点，通道数最高 16。
- **任务与评分**  
  表 6–7 归纳了 5 项精确任务和对应的 MCQ 变体：
  | 任务 | 精确答案格式 | 连续评分 | MCQ 选择项 |

  | **Classify** | `{"kind": "Trend", "start": ..., "end": ...}` | $\mathbf{1}_{\hat{k}=k} \cdot \text{IoU}$ | 异常类别选项 |

#### 2.3 强化学习后训练（第 4.1 节）
- **算法**：GRPO（Group Relative Policy Optimization），无监督热身，全参数调优。
- **训练循环**：每步由生成器直接合成一批新样本，避免重复。

### 6. 主要结论与发现
1. **精确检索任务上 TimeRLM 大幅领先**  
   AnomalyXL‑Localize 上，TimeRLM 在定位（IoU 0.682）、带证据分类（0.745）、全通道定位（0.551）和超前/滞后（0.978）均远超所有基线，而单次通过最佳成绩仅为 0.329 (Localize) 和 0.072 (Classify+Evidence)。
2. **MCQ 形式高估了 TSLM 的检索能力**  
   经典特征+GBT 在 MCQ 上可达平均 0.81，但精确评分下骤降至 0.30，说明选择题可由汇总统计破解，无法反映真正的定位精度。
3. **递归交互对长上下文稳定**  
   随信号长度从 16k 增至 131k，单次通过模型性能下降明显（图像模式 Localize 从 0.48 降至 0.16），而 TimeRLM 保持在 0.61–0.79 区间。
4. **强化学习后训练提升效率与泛化**  
   RL 后训练将 4B 小模型的 Localize IoU 从 0.205 提升至 0.538，超出 32B Toto 的 0.323；同时交互轮数约为未训练模型的三分之一。在真实 ECG 和睡眠数据上，RL 后训练的 TimeRLM 保持了良好的零样本分类性能（F1 0.45 vs 0.36），且超越了所有 TSLM。
5. **合成训练可产生域外泛化**  
   尽管 TSLM 在未见临床数据上全部崩溃（IoU ≤ 0.004），TimeRLM 仍能进行有效分类与部分定位，提示基于代码的交互环境提供了信号无关的学得规程。

### 7. 优点
- **方法论创新**：首次将递归语言模型引入时间序列异常定位，通过代码执行和视觉能力实现细粒度交互，避免了全量入窗的弊端。
- **公开基准**：AnomalyXL 连同生成器与 RL 环境开源，支持可配置难度，填补了长上下文精确检索基准的空白。
- **全面的评估**：覆盖合成数据、真实软件遥测数据和临床数据，包含多个基线（经典、TSLM、VLM、单次 LLM）、多种评分尺度（IoU、F1、分类准确率等），分析扎实。
- **强化学习整合**：将在线合成训练与 GRPO 结合，增强了模型效率和泛化能力，且无需监督微调预热。
- **良好的跨域迁移**：只用合成数据训练即可维持真实临床信号上的竞争力，证实了代码交互范式的鲁棒性。

### 8. 不足与局限
- **合成异常的表达力有限**：AnomalyXL 的异常均为参数化程序注入（如阶跃、尖峰），而现实世界异常可能更加模糊且依赖上下文语义，此基准主要测量数值偏离的精确检索。
- **比较存在规模不对等**：Toto 使用 32B VLM 与专用预训练编码器，而其他 TSLM 仅为 4B，文中已指出需谨慎解读，但效应量可能被低估或高估。
- **消融实验尚不完整**：未严格分离“代码访问”与“递归”各自的贡献，也未对比等量 SFT 与 RL 的效果差异（作者在讨论中已指出未来工作）。
- **计算开销未量化**：递归多轮交互和 RL 训练的算力、显存消耗未报告，可能在实际部署中成为瓶颈。
- **泛化局限**：泛化测试仅包含了两个临床域，未涉及工业、金融等其他典型长上下文监控场景；真实数据上的精确定位仍然很低（IoU 接近零），说明从合成到真实的定位迁移尚有较大挑战。
- **子 RLM 调用深度受限**：实验主要使用了深度‑1 递归，更深的搜索树潜力未被探索。
