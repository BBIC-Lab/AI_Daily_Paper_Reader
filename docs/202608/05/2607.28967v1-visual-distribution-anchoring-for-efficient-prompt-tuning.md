## 摘要
提示微调以少量可训练参数适应视觉-语言模型，但现有方法在效率和适应性间权衡：静态文本提示可能过拟合源类别，图像条件提示增加逐实例计算，多模态微调修改视觉分支。我们提出VDA（视觉分布锚定），一种无训练的目标适应框架，通过从无标签目标池离线估计的类别级视觉原型增强冻结的语义分类器。我们首先探究能否从类别名称合成原型。文本到质心映射器可重建留出的源原型，但在数据集偏移下失效，因为类别名称指定语义身份而非目标域外观。预言分析确认真实目标原型具有高判别力。因此，VDA使用冻结的语义和域模板分类器将无标签目标图像划分为类别相关组。置信度排序的图像特征形成归一化原型，通过一个全局权重与语义分类器融合。适应无需目标标签、目标端优化、统一类别先验假设、迭代细化或测试查询访问，并产生一个固定的可缓存分类器。对照实验表明，特定类别划分驱动增益，并且视觉局部伪标签错误尽管类别不正确，仍可能有用。在十个ImageNet到目标的迁移中，相同的冻结设计将零样本CLIP、TCP和MaPLe分别提高3.22、3.39和3.35个百分点，在每个设置下改进了十个目标中的九个。其视觉修正进一步将无泄漏的PromptKD提高2.79个百分点，补充了零样本、源提示、多模态提示和目标蒸馏分类器。

## Abstract
Prompt tuning adapts vision--language models with few trainable parameters, but existing approaches trade off efficiency and adaptation: static textual prompts can overfit source classes, image-conditioned prompts add per-instance computation, and multimodal tuning modifies the visual branch. We propose VDA (Visual Distribution Anchoring), a training-free target adaptation framework that augments a frozen semantic classifier with class-level visual prototypes estimated offline from an unlabeled target pool. We first ask whether prototypes can be synthesized from class names. A text-to-centroid mapper reconstructs held-out source prototypes but fails under dataset shift because class names specify semantic identity, not target-domain appearance. An oracle analysis confirms that true target prototypes are highly discriminative. VDA therefore uses frozen semantic and domain-template classifiers to partition unlabeled target images into class-correlated groups. Confidence-ranked image features form normalized prototypes, fused with the semantic classifier using one global weight. Adaptation requires no target labels, target-side optimization, uniform class-prior assumption, iterative refinement, or test-query access, and yields a fixed, cacheable classifier. Controlled experiments show that class-specific partitioning drives gains and that visually local pseudo-label errors can remain useful despite being class-incorrect. Across ten ImageNet-to-target transfers, the same frozen design improves zero-shot CLIP, TCP, and MaPLe by 3.22, 3.39, and 3.35 points, respectively, improving nine of ten targets in every setting. Its visual correction further improves leakage-free PromptKD by 2.79 points, complementing zero-shot, source-prompted, multimodal-prompted, and target-distilled classifiers.

### 1. 论文的核心问题与整体含义

- **研究背景**：视觉—语言模型（如 CLIP）可通过提示微调（prompt tuning）适配下游任务，但现有方法面临效率与适应性之间的权衡。
  - 静态文本提示（如 CoOp）容易在源类别上过拟合。
  - 图像条件提示（如 CoCoOp）增加逐样本计算开销。
  - 多模态方法（如 MaPLe）需要同时修改语言和视觉分支，增加了复杂度。
- **核心问题**：如何在**无目标域标签、无目标端训练、无测试时查询访问**的条件下，有效将源预训练的分类器适配到目标域，同时保持极低的计算与存储开销。
- **整体含义**：本文发现，从类别名称直接合成目标域视觉原型（text-to-centroid）即便能重建源域原型，也无法应对域偏移；但真实目标域原型具有很强的判别力。因此，提出**视觉分布锚定（VDA）**，一种免训练框架，利用无标签目标池离线估计类别级视觉原型，并以固定权重与冻结语义分类器融合，实现即插即用的目标域适应。

### 2. 方法论

- **核心思想**：用冻结的语义分类器和手工设计的域模板分类器对无标签目标图像进行**硬划分（hard partition）**，为每个类别构建置信度排序的视觉原型，再与原有语义分类器进行全局加权融合。
- **关键技术细节与流程**：
  1. **双分类器得分与硬分配**：
     - 给定冻结语义分类器得分 $s_{\text{sem}}(x, c)$ 和固定域模板分类器得分 $s_D(x, c)$（域模板如“一张 $c$ 的近距离航拍照片”）。
     - 计算融合得分 $a_{ic} = \frac{1}{2} \left[ s_{\text{sem}}(x_i, c) + s_D(x_i, c) \right]$。
     - 硬分配：$\hat{c}_i = \arg\max_c a_{ic}$，每个图像仅归入一个预测类。
  2. **置信度排序与支持集选取**：
     - 定义置信度 $q_i = \left[\text{softmax}(a_i)\right]_{\hat{c}_i}$。
     - 对每一类 $c$，选取置信度前 $K$ 的图像特征（若不足 $K$ 则全选），得到支持集 $\mathcal{S}_c$，其中 $|\mathcal{S}_c| = \min(K, |\mathcal{I}_c|)$。
  3. **归一化视觉原型估计**：
     - 对支持集中的图像特征 $v_i$（CLIP 归一化后）求平均并再次归一化：
       $$\hat{\mu}_c = \text{norm}\!\left( \frac{1}{|\mathcal{S}_c|} \sum_{i \in \mathcal{S}_c} v_i \right)$$
  4. **语义—视觉融合**：
     - 视觉得分：$s_{\text{vis}}(x, c) = \gamma\, \text{norm}(f_V(x))^\top \hat{\mu}_c$。
     - 融合权重：若 $|\mathcal{S}_c| > 0$ 则 $\lambda_c = \lambda$，否则 $\lambda_c = 0$（无支持时回退到纯语义分类器）。
     - 最终得分：
       $$s_{\text{VDA}}(x, c) = (1-\lambda_c) s_{\text{sem}}(x, c) + \lambda_c s_{\text{vis}}(x, c)$$
     - 若语义分类器与视觉原型共享同一 CLIP 特征空间（如零样本 CLIP、TCP），则可预先计算缓存类向量：
       $$\bar{w}_c = \begin{cases} (1-\lambda) w_c^{\text{sem}} + \lambda \hat{\mu}_c, & |\mathcal{S}_c| > 0 \\ w_c^{\text{sem}}, & |\mathcal{S}_c| = 0 \end{cases}$$
  5. **跨分类器附加**：对于不共享特征空间的分类器（如 MaPLe、PromptKD），直接用其语义逻辑与同一批视觉逻辑按式 $s_{\text{VDA}} = (1-\lambda_c) \tilde{s}_{\text{sem}} + \lambda_c s_{\text{vis}}$ 组合。
- **复杂性与部署**：整个适应过程仅需一次离线遍历无标签目标池，无迭代优化、无目标先验假设，最终产生一个可缓存的固定分类器，推理时与普通 CLIP 线性分类成本相同。

### 6. 主要结论与发现

- **文本到质心映射不足以实现目标域原型迁移**：虽然源域重建精度高，但预测原型在目标域上与真实质心的类别级结构化对齐很差。
- **真实目标原型具有很强的判别力**：oracle 原型可使分类准确率从 49.91% 提升至 66.16%。
- **VDA 能有效利用无标签目标池**：仅通过一次硬划分与原型估计，将 TCP 从 65.82% 提升至 69.21%，且优点不依赖于某一种特定的源提示架构。
- **通用且互补**：同一视觉修正对零样本 CLIP (+3.22)、多模态 MaPLe (+3.35)、蒸馏 PromptKD (+2.79) 均带来稳定提升。
- **类特定硬划分为主要驱动力**：类别对应关系（而非通用目标统计或置信度排名）贡献主要增益；且视觉邻近的伪标签错误即使类别不正确，仍能提供有用的外观信息。
- **方法极简高效**：无需目标标签、梯度迭代、先验假设或测试查询，最终产生缓存分类器，适合实际部署。

### 7. 优点

- **免训练、免优化**：完全冻结所有预训练组件，适应过程仅涉及算术运算和硬分配，实现极低开销。
- **高兼容性**：与零样本、源提示、多模态提示、目标蒸馏等多种分类器兼容，无需改变原分类器内部结构。
- **部署友好**：共享空间时可预计算固定类向量，推理成本与标准 CLIP 一致。
- **解释性强**：通过 oracle 实验与文本到质心失败分析，清晰揭示了域偏移下语义信息的局限性与视觉信息的必要性。
- **鲁棒的原型构建**：硬分配避免平衡软分配导致的坍缩，置信度截断与零支持回退机制增强了适应性。
- **控制实验翔实**：通过共同质心、打乱原型、随机采样等充分验证了类特定划分是关键，而非任意目标域统计信息。

### 8. 不足与局限

- **依赖无标签目标池**：需要一定规模且具代表性的目标域无标签图像，无法在完全无目标图像或样本极少时工作。
- **依赖领域模板**：需手工编写域描述文本，当部署域未知或异质时可能不准确，影响分配质量。
- **视觉空间固定**：原型估计与视觉逻辑均基于 CLIP 默认视觉编码器，若语义分类器使用不同视觉空间（如 MaPLe 修改视觉分支、PromptKD 使用蒸馏），则需保留原始 CLIP 得分流，增加推理开销。
- **对难覆盖类别有限**：$K=32$ 是上限而非保证；一些细粒度类别可能没有伪支持，只能回退至纯语义分类器，且竞争类的视觉修正可能干扰决策边界。
- **融合权重固定**：单一全局 $\lambda$ 虽稳定但未能利用类间可靠性差异，动态权重估计仍有提升空间。
- **评估并非完全盲测**：设计参数在5个开发集上选定，后续剩余数据集可能受早期探索影响，但作者已指出这一限制。
