## 摘要
模式链接是Text-to-SQL系统的关键组成部分，但现有方法往往在上下文建模能力、基于分数的可控性和推理效率之间进行权衡。我们提出AttnLink，一个基于注意力的框架，将大语言模型的内部注意力转化为模式项的连续相关性得分。AttnLink从生成起始位置提取对候选模式片段的注意力，从而在单次预填充过程中对所有候选项进行排序，无需自回归解码。我们开发了两种变体：AttnLink-U直接探测预训练注意力而不更新参数，AttnLink-S通过直接监督将注意力分布与黄金模式项对齐。为了提高对多个相关模式项的覆盖，AttnLink-S结合了集合质量目标与自适应概率下限正则化器。所得分数支持通过温度缩放和累积质量选择进行事后精确率-召回率控制。在Spider、BIRD和Spider2-SQLite上的实验表明，AttnLink-S的mAP分数分别达到99.22%、95.95%和83.29%，模式链接延迟仅为毫秒级。在九种生成器-数据集设置中的七种里，它还为下游SQL生成带来了最佳或并列最佳的执和准确性。

## Abstract
Schema linking is a critical component of Text-to-SQL systems, but existing approaches often trade off contextual modeling capacity, score-based controllability, and inference efficiency. We introduce AttnLink, an attention-based framework that converts LLMs' internal attention into continuous relevance scores for schema items. AttnLink extracts the attention from the generation-start position to candidate schema spans, enabling all candidates to be ranked in a single prefill pass without autoregressive decoding. We develop two variants: AttnLink-U, which directly probes pretrained attention without parameter updates, and AttnLink-S, which aligns the attention distribution with gold schema items through direct supervision. To improve coverage of multiple relevant schema items, AttnLink-S combines a set-mass objective with an adaptive probability-floor regularizer. The resulting scores support post-hoc precision-recall control through temperature scaling and cumulative-mass selection. Experiments on Spider, BIRD, and Spider2-SQLite show that AttnLink-S achieves mAP scores of 99.22%, 95.95%, and 83.29%, respectively, with millisecond-scale schema-linking latency. It also yields the best or tied-best execution accuracy for downstream SQL generation in seven of nine generator-dataset settings.

### 1. 论文的核心问题与整体含义
Text-to-SQL 任务中，**模式链接（Schema Linking）** 负责从数据库模式中识别出与自然语言问题相关的表和列，其质量直接影响下游 SQL 生成。现有方法普遍存在**三方面权衡**：
- 生成式方法（如 prompt 或微调 LLM）具有强语义建模能力，但产生离散集合，难以事后控制精确率与召回率；
- 检索式方法（如基于嵌入或交叉编码器）可提供连续分数，但缺乏大模型级别的上下文与组合语义建模能力；
- 许多方法依赖自回归解码、独立重排序模型或修改推理流程，**推理效率低**。

因此，论文提出 **AttnLink**，旨在**将 LLM 内部注意力直接转化为模式项的相关性分数**，同时满足语义容量、基于分数的可控性和高推理效率三个要求。

### 2. 方法论
**核心思想**：利用 LLM 在生成起始位置（生成锚点）对候选模式项 token 的注意力分布作为相关性信号，实现**单次预填充（prefill）内对所有候选项的连续排序**，无需自回归解码。

#### 2.1 两种变体
- **AttnLink-U（免训练探测）**  
  直接提取预训练 LLM 某一选定注意力头在生成锚点处的注意力权重，经候选 span 的均值池化得到原始分数 $s_i$，再通过温度缩放与归一化得到候选分布 $\pi^{(\tau)}_i$，无需任何参数更新。

- **AttnLink-S（有监督对齐）**  
  通过直接监督将注意力分布与黄金模式项对齐，优化以下目标：
  - **集合质量损失**：$L_{\text{set}} = -\log(P_G + \epsilon)$，其中 $P_G = \sum_{i\in I^+} \pi_i$ 为所有正类候选的概率之和；
  - **自适应概率下限正则化**：$L_{\text{floor}}(\rho) = \frac{1}{|I^+|}\sum_{i\in I^+} \max\left(0,\ \log\frac{f(I^+;\rho)+\epsilon}{\pi_i+\epsilon}\right)$，$f(I^+;\rho)=\frac{\rho}{|I^+|}$，$\rho$ 控制联合覆盖度。  
  最终损失 $L = L_{\text{set}} + L_{\text{floor}}(\rho)$，防止少数易分正例占据大部分概率而遗漏其他必要项。

#### 2.2 推理与后验控制
- **温度缩放**：$\pi_i^{(\tau)} = \frac{\exp(\log(s_i+\epsilon)/\tau)}{\sum_{r=1}^n \exp(\log(s_r+\epsilon)/\tau)}$，$\tau>1$ 使分布更平缓（偏向高召回），$\tau<1$ 更尖锐（偏向高精确率）。
- **Top-p 累积质量选择**：按 $\pi^{(\tau)}$ 降序累加概率，直到达到阈值 $p$，选出的最小前缀即为链接结果。  
整个过程仅需一次标准 prefill，与 vLLM 等框架兼容，延迟仅毫秒级。

### 6. 主要结论与发现
- AttnLink 可将 LLM 预训练注意力蒸馏为模式相关性分数，**单次 prefill 完成排序**，无需自回归解码。
- **AttnLink-S** 在各数据集上达到顶级 mAP（Spider 99.22%、BIRD 95.95%、Spider2-SQLite 83.29%），同时保持高严格召回率；**无需训练数据的跨数据集迁移仍表现强劲**。
- 在下游 SQL 生成中，AttnLink-S 在 **7/9 个生成器‑数据集组合**中取得最佳或并列最佳 EX，且通过调整温度可进一步适应不同生成器的噪声偏好（如在 BIRD 上对 Qwen2.5-Coder-7B 将 EX 从 53.0% 提升至 60.7%）。
- 注意力信号集中在少数中间‑后期层与特定头部且对候选顺序鲁棒，复制式指令对诱导有用信号至关重要。

### 7. 优点
- **效率极高**：单次 prefill、毫秒级延迟，与标准服务框架无缝集成。
- **灵活可控**：连续分数 + 温度缩放 + top-p 累积选择，可在推理时自由调节精确率‑召回率，无需重训。
- **架构兼容性广**：在密集 Transformer、混合注意力、MoE 等多种 LLM 上均有效。
- **训练轻量**：仅需 LoRA 微调少量参数，且少量校准样本即可选出最优头。
- **双重范式统一**：免训探测（AttnLink-U）与有监督对齐（AttnLink-S）共享同一推理流程，兼顾零样本与高性能场景。

### 8. 不足与局限
- **对复制式提示的依赖**：AttnLink-U 的性能高度依赖于“随机复制一个标识符”的提示设计，若替换为通用推理指令，mAP 严重下降（相对降幅超 60%）；AttnLink-S 也可能受限于该提示分布。
- **注意力头需校准**：AttnLink-U 需在一个小校准集上选定最优层‑头对，且所选头在不同数据集间迁移性虽好，但若换了完全不同的模型家族，仍需重新校准。
- **有监督变体依赖标注**：AttnLink-S 需要黄金模式链接标注，限制了无标注场景下的应用；训练分布与测试数据库差异大时可能受影响。
- **下游生成的温度敏感性**：最优 $\tau$ 依赖于具体的 SQL 生成器，实际部署中可能需要针对不同生成器进行离线的温度搜索，增加了调参成本。
- **长尾项覆盖**：虽然 floor 正则化改善了多正例覆盖，但在极端稀疏的正例场景下，极低概率的必需项仍可能被 top-p 阈值截断。
- **未探索多轮/交互式场景**：所有实验均基于单轮生成，未评估 AttnLink 在多轮对话或迭代修正中的表现。
