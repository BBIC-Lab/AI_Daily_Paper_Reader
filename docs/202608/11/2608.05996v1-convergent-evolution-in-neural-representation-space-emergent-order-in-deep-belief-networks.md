## 摘要
深度信念网络（DBNs）在没有类别监督的情况下学习层次化生成模型。在此，我们探讨这个纯粹无监督的过程是否仍然根据未知的数据类别组织内部表示。我们使用广义判别值（GDV）、仅在训练后应用的监督探针、基于重建的抽象距离度量、有效维度和自由样本生成，分析了在MNIST、Fashion-MNIST和KMNIST上训练的DBN的连续层。值得注意的是，尽管在DBN训练期间没有标签信息，跨数据集和网络宽度，特定类别的聚类通常随深度增加而增强。对照实验表明，这种效应取决于学习到的特征结构，不能由随机变换、权重边缘分布、降维或sigmoid饱和解释。第一个隐藏层也经常使类别身份对于线性和非线性探针更容易获取。随着深度的增加，表示变得越来越紧凑和原型化，因为神经元获得了相关的特征方向。同时，GDV和探针准确度揭示了类别结构的互补方面：改进的平均聚类可以与少数困难类别对的可获取性降低共存。这些发现表明，逐层生成学习可以自发地揭示并逐步放大未标记数据中与类别相关的结构。

## Abstract
Deep Belief Networks (DBNs) learn hierarchical generative models without class supervision. Here, we ask whether this purely unsupervised process nevertheless organizes internal representations according to the unknown data classes. We analyze successive layers of DBNs trained on MNIST, Fashion-MNIST, and KMNIST using the Generalized Discrimination Value (GDV), supervised probes applied only after training, a reconstruction-based measure of abstraction distance, effective dimensionality, and free sample generation. Remarkably, class-specific clustering generally increases with depth across datasets and network widths, although no label information is available during DBN training. Control experiments show that this effect depends on the learned feature structure and cannot be explained by random transformations, weight marginals, dimensionality reduction, or sigmoid saturation. The first hidden layers also frequently make class identity more accessible to linear and nonlinear probes. With greater depth, representations become increasingly compact and prototype-like as neurons acquire correlated feature directions. At the same time, GDV and probe accuracy reveal complementary aspects of class structure: improved average clustering can coexist with reduced accessibility for a few difficult class pairs. These findings demonstrate that layer-wise generative learning can spontaneously uncover and progressively amplify class-related structure in unlabeled data.

### 论文提出的方法论

*   **核心思想**：通过贪婪、逐层、完全无监督的方式训练DBN，并构建一套多维度评估体系，在不修改训练好的网络的情况下，直接测量每一层表征的类别聚类质量、信息保真度、维度压缩程度和类别可解析性。
*   **关键技术细节**：
    *   **广义判别值（GDV）**：一种无量纲、平移和缩放不变的标量，用于量化带标签数据在不同表征空间中的聚类分离程度。它的核心是标准化点间距离后，比较平均类内距离 $\bar{d}(C_l)$ 和平均类间距离 $\bar{d}(C_l, C_m)$，定义为：
        $$GDV = \frac{1}{\sqrt{D}} \left[ \frac{1}{L} \sum_{l=1}^{L} \bar{d}(C_l) - \frac{2}{L(L-1)} \sum_{l=1}^{L-1} \sum_{m=l+1}^{L} \bar{d}(C_l, C_m) \right]$$
        其中 $D$ 是维度，$L$ 是类别数。$GDV$ 为负且越小，表示类间分离越强。
    *   **抽象距离（Abstraction Distance）**：操作上定义为输入图像 $x_n$ 与其经过前 $l$ 层编码-解码后的重建图像 $\hat{x}_n^{(l)}$ 之间的均方误差（MSE）。这量化了表征在向上传递过程中丢弃了输入数据的多少细节。
        $$D^{(l)}_{abs} = \frac{1}{N D_0} \sum_{n=1}^{N} \sum_{d=1}^{D_0} (x_{n,d} - \hat{x}^{(l)}_{n,d})^2$$
    *   **有效维度（Effective Dimensionality）**：使用基于协方差谱的参与率（Participation Ratio）来估计表征中活跃的独立信息维度数量。它不直接等于神经元数量，而是衡量方差分布的均匀程度。
        $$D^{(l)}_{eff} = \frac{(\sum_{i=1}^{D_l} \lambda_i)^2}{\sum_{i=1}^{D_l} \lambda_i^2}$$
        其中 $\lambda_i$ 是层表征协方差矩阵 $C^{(l)}$ 的特征值。研究人员进一步将有效维度的下降分解为由“神经元方差异质性”和“神经元间相关性（冗余）”两部分贡献。
    *   **分类探针（Classification Probes）**：在训练好DBN的每一层冻结表征上，单独训练三个监督分类器来评估类别信息的“可获取性”，包括线性逻辑回归、基于无监督K-Means中心的高斯核分类器、以及RBF核支持向量机（SVM）。

### 实验设计

*   **数据集**：使用三个具有相同格式（`28×28` 灰度图）、但视觉复杂度和内容不同的标准分类基准数据集：
    *   **MNIST**: 手写数字（0-9）。
    *   **Fashion-MNIST**: 衣物商品（如T恤、裤子、鞋包等）。
    *   **KMNIST (Kuzushiji-MNIST)**: 日本草书字符（视觉上比MNIST更复杂）。
*   **基准与对比方法**：
    *   **主体网络**：在 `{100, 50, 30}` 三种神经元宽度，及默认10层（MNIST额外拓展至30层）的DBN，使用对比散度（CD-1）贪婪逐层训练，无监督微调。
    *   **对照实验**：为验证无监督聚类效应的来源，进行了一系列消融研究：
        *   **训练控制**：与使用两步 Gibbs 采样（CD-2）的DBN对比；与未训练的随机权重网络对比。
        *   **结构破坏控制**：对训练好的DBN的权重进行“特征洗牌”（独立打乱每个神经元输入权重的像素坐标），保留权重值分布但破坏空间结构。
        *   **表征控制**：比较使用sigmoid前后的激活值；构建无sigmoid的纯仿射路径；比较概率编码与随机二值采样（Bernoulli state）的GDV。

### 主要结论与发现
1.  **无监督类别涌现**：在没有类别标签的情况下，DBN的隐藏层能够自发地、逐层增强数据的类别聚类分离度（GDV单调下降），这一发现在MNIST、Fashion-MNIST和KMNIST上均成立。
2.  **效应归因于学习到的结构**：对照实验排除了随机变换、权重分布、Sigmoid饱和、维度变化等非学习因素，证明类别分离的增强是由CD算法学习到的特定特征结构所致。
3.  **浅层增益与深层损失非对等**：第一层或前几层不仅能压缩数据，甚至能使类别信息对线性/非线性分类器更“可获取”。然而在更深的层次，尽管全局聚类（GDV）持续改善，但由于少数困难类对（如MNIST的4-9， 5-8， 3-5）的信息丢失，导致分类探针的准确率下降。
4.  **维度塌缩源于权重冗余**：DBN深层的有效维度急剧下降，其主要原因不是神经元完全失活，而是大量神经元学习到了相似的（平行或反平行的）特征权重方向，导致它们的活动高度相关，形成功能冗余。
5.  **生成轨迹与表征演化分离**：网络自由生成的样本（dreaming）质量随深度变化呈现非单调且数据集特异的现象（如浅层模式崩塌，深层样本变丰富），这表明生成质量与表征的判别式几何结构（GDV）和重建保真度（抽象距离）是非等价的属性。

### 优点
*   **多维度、系统性的评估框架**：不依赖单一指标，而是联合几何（GDV）、信息（探针、抽象距离）、压缩（有效维度）和生成（样本可视化）等多个视角，立体刻画了DBN的表征演化，揭示了各属性间的解耦关系。
*   **严谨的归因分析**：设计了环环相扣的对照实验（特征洗牌、纯仿射路径、标签随机化等），强有力地证明了观测到的类别结构来源于“学习”，而非网络架构或数据处理的副作用。尤其对“维度塌缩”根源的分解（方差vs.协方差）非常深刻。
*   **现象精细化阐释**：清晰揭示了“全局聚类改善”与“局部可分离性恶化”可以共存的反直觉现象。这在概念上是重要的，它警告研究者不能简单地将无监督的聚类指标等同于下游分类性能的提升。

### 不足与局限
*   **数据集与任务局限性**：研究仅在三个相对简单、格式统一的灰度图像数据集上进行，其结论是否能推广到更复杂的自然图像或非视觉模态数据上，尚待验证。
*   **只分析了一种模型架构**：聚焦于DBN（堆叠RBM），虽然这是合适的模型系统，但未与其他现代无监督生成模型（如VAE、扩散模型）的层级表征进行类比分析，限制了结论的普适性。

*   **生成质量评估较为主观**：对“自由生成”的结果评估主要通过展示少量样本进行定性分析，缺乏定量、大规模的生成质量和多样性评价指标支持。
