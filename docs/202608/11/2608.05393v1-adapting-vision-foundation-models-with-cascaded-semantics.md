## 摘要
提示调优是自然语言处理中一种领先的参数高效适配范式，最近已扩展到计算机视觉。视觉提示调优（VPT）通过更新少量额外的提示参数来适配预训练的视觉Transformer（ViT）。然而，现有的视觉提示是随机初始化的，并未利用先验知识，比如自然语言处理中的指令。我们通过向VPT注入两种互补的语义先验来解决这一差距。基本的图像先验，包括颜色、纹理和形状，通过经典的手工设计算子提取并注入输入空间，而自注意力图在特征空间中提供实例感知语义。我们进一步提出了一种级联方案，将两种先验整合到整个ViT适配过程中。在34个具有挑战性的图像分类数据集上的实验表明，在仅调优0.74%的ViT参数的情况下，下游适配效果更优。项目页面：https://xixiaouab.github.io/Cascaded-Semantics/。

## Abstract
Prompt tuning, a leading parameter-efficient adaptation paradigm in NLP, has recently been extended to computer vision. Visual prompt tuning (VPT) adapts pre-trained vision transformers (ViTs) by updating a small set of additional prompt parameters. However, existing visual prompts are randomly initialized and do not exploit prior knowledge, such as instructions in NLP. We address this gap by injecting two complementary semantic priors into VPT. Fundamental image priors, including color, texture, and shape, are extracted with classical hand-crafted operators and injected into the input space, while self-attention maps provide instance-aware semantics in the feature space. We further propose a cascaded scheme that integrates both priors throughout ViT adaptation. Experiments on 34 challenging image classification datasets demonstrate superior downstream adaptation while tuning only 0.74% of ViT parameters. *   **核心问题**：现有VPT方法存在两个关键缺陷。
    1.  **随机初始化**：视觉提示通常是随机初始化的，没有利用任何先验知识，这与NLP中作为明确指令的提示形成对比，限制了其性能上限。
    2.  **缺乏可解释性**：可学习提示的行为很少在表征层面被分析，它们像一个“黑盒”参数优化过程，不具备实例感知能力，难以解释。
*   **整体含义**：本研究旨在弥补上述差距，通过注入可解释的、结构化的语义先验知识来“锚定”随机提示，从而在保持参数高效的同时，提升VPT的性能和可解释性。

### 2. 方法论

本方法的核心思想是在VPT框架中注入两类互补的语义先验，并通过级联设计将它们贯穿整个ViT的适配过程。

*   **核心思想与关键技术细节**：
    *   **为输入空间注入基本图像先验**：针对VPT的输入空间，利用经典手工算子直接从输入图像 $X$ 中提取颜色直方图 $\sigma_c(X)$、纹理 $\sigma_t(X)$ 和形状 $\sigma_s(X)$。这些先验作为不可学习的“硬提示”与随机初始化的可学习提示 $P_1$ 拼接，形成一个综合提示 $\tilde{P}_1$。公式表示为 $\tilde{P}_1 = P_1 \otimes FC(\sigma_c(X) \otimes \sigma_t(X) \otimes \sigma_s(X))$，其中 $FC$ 是一个用于维度对齐的可学习线性层。
    *   **为特征空间注入实例感知语义**：在特征空间，利用自注意力图 $A_i$ 作为实例感知的语义信号。对于第 $i$ 层，其提示 $\tilde{P}_i$ 由当前层的随机可学习提示 $P_i$、当前层的自注意力图 $A_i$、前一层的提示 $P_{i-1}$ 和前一层的自注意力图 $A_{i-1}$ 四部分拼接而成。公式为 $\tilde{P}_i = FC_i(A_i) \otimes P_i \otimes FC_{i-1}(A_{i-1}) \otimes P_{i-1}$。这种跳跃连接实现了语义的级联，使深层提示能够利用浅层积累的知识。
    *   **引入重加权适配器**：在最终的分类头之前，引入一个轻量级的“FC-Softmax-FC”模块作为重加权适配器，对输出特征进行通道级的重校准，以增强其与分类任务的相关性。

*   **算法流程**：
    1.  对于每个输入图像，通过手工算子提取基本图像先验，并与可学习提示拼接，作为第一层Transformer的输入。
    2.  对于后续的每个Transformer层，计算其自注意力图，并将其与当前层和前一层的可学习提示及自注意力图级联，形成该层的提示。
    3.  将拼接后的提示与前一层的输出特征一同输入到当前Transformer层。
    4.  整个过程仅更新可学习提示 $P_i$ 和线性投影层 $FC$，ViT骨干网络保持冻结。
    5.  最终输出特征经过重加权适配器校准后，送入分类头 $h$ 得到预测结果。
